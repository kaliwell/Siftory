# 第三方源码 / Third-party source

## 取得源码

本目录随 Siftory 提供源码附件 `canvas-rust-sources.zip`。在软件中打开 Settings（设置）→ Third-party licenses（第三方许可），进入 `covered-source`，解压该 ZIP 即可查看源码、许可原文与版本索引。取得这些文件无需联网、注册账户、另行付费或接受限制开源源码权利的条件。

附件包括 cssparser 0.37.0、cssparser-color 0.5.0 和 cssparser-macros 0.7.0 的原始发布源码及 MPL-2.0 许可；同时保留其他已识别 Rust 组件的原始归档及各自许可。组件路径、上游地址、原始校验和及可读源码位置见 ZIP 内 README 和源码索引。

你可以依 Mozilla Public License 2.0 使用、修改及再分发受其覆盖的源码。Siftory 的其他条款不限制这些源码权利；各文件的原有版权、许可和免责声明继续适用。官方许可全文也见 https://www.mozilla.org/en-US/MPL/2.0/ 。

本附件不包含 Siftory 的专有应用源码或模型权重。它明确覆盖所列组件，不代表 canvas、Skia 或其他原生库的完整依赖清单。不同组件和版本须单独核对，不能把本附件用于未匹配的二进制版本。
