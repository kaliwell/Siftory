# Siftory v1.0.1-alpha.23

> 状态：当前  
> 更新日期：2026-11-05

Windows x64 Online Alpha，包含 Alpha 22 界面及 11 月 5 日维护页审计修复：收藏上下文与迟到响应保护、失败移除反馈、重复操作保护，以及折叠/隐藏时暂停数据源轮询。

新增手动触发的 Windows 托管打包流程：从源码重新编译 Electron 原生模块，记录该本地构建产物的指纹与源提交，保持其他外部资源的固定哈希；按在线 profile 下载并校验字体，执行既有构建、资源、归档和独立的实际解包启动检查后上传安装包、SHA256 和构建证据。它不依赖自托管模型缓存，也不捆绑 AI 模型。

本次是未签名 Alpha 安装包；具体打包与检查结果以对应 Actions 构建记录为准。解包启动与归档检查不等同于旧版覆盖升级通过。此前旧安装升级时的访问拒绝与程序文件缺失尚未在用户实机关闭，参见[升级验收交接](2026-11-05-alpha22-audit-fixes.md)和[备份规则](../../BACKUP_SAFETY.md)。

完整旧版 UI 矩阵仍含已移除的界面选择器，作为诊断运行并单独记录结果，不计为启动检查通过。安装包附件 validation-status.json 显示其实际 outcome；正式受控发布流程保持不变。独立启动检查要求在 nonce 验证的临时配置中显示并接受协议、加载实际主界面与 Native 模块，且页面没有捕获到异常；它不能替代完整 UI、模型或覆盖升级验收。
