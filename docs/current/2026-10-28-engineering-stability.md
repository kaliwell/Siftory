## 当前状态与执行边界

基于已合并素材库界面的 Alpha 10 源码。维护者在本轮会话确认核心搜索已测试通过，原搜索验收项按维护者实测关闭；未提供具体样本与日志，本轮执行者没有重跑 Windows 原生搜索，也未把这一结论扩展到全部硬件或恢复场景。

执行者为 Codex，模型精确版本未知；未启动子代理。改动位于独立的本地优化副本，不覆盖上传文件或前轮合并包，不发布安装器。

## 本轮修改

- 收藏夹列表刷新增加请求代次与组件生命周期保护。旧成功响应不覆盖新列表或选择；旧失败不覆盖当前错误状态；卸载后不更新状态或继续发起读取。失败仍向直接调用者抛出，保留创建/重试流程的错误语义。
- 新增实际 hook 源码的可控异步测试，覆盖乱序成功/失败、重试、选择复位、卸载和 StrictMode effect 重放。模拟 hooks/IPC，用于验证请求所有权，不替代真实 React 浏览器测试。
- 通过 `test:desktop:browser` 汇总工作台、现代桌面、搜索生命周期和素材库四条浏览器回归；源码 CI、受控构建和正式 release gate 采用相同入口。
- 受控构建在打包前补原生模块构建和当前工作区原生回归；源码 CI 补架构检查和 SQLite 元数据回归。真实 Windows 失败会阻断流程，不跳过断言。
- `test:storage:metadata` 运行现有 SQLite 回归，含迁移中断回滚、历史部分迁移恢复、导入导出哈希一致和事务回滚。它不代表完整用户数据备份、向量或共享盘恢复已验收。
- 主 README 版本同步为 alpha.10；保留旧发布记录的历史结果，另追加维护者后续验收状态。

## 数据边界与后续验收

本轮不改变 SQLite、JSONL、向量数据结构和现有跨存储恢复协议，也不迁移用户数据。后续先追踪实际写入链与既有事务/outbox，再决定是否调整，避免重复引入第二套协议。

| 数据类别 | 当前优化原则 | 验收重点 |
|---|---|---|
| SQLite 关系与元数据 | 保持权威写入与现有迁移/事务边界 | 中断回滚、版本恢复、导出再导入一致 |
| JSONL | 区分遗留权威存储、迁移、日志与交换格式，不一刀切删除 | 逐表确认读写来源后再收敛重复状态 |
| 向量 | 高成本派生数据，关联素材及模型/索引代次 | 变化失效、任务重放、断点续建 |
| ANN/缩略图等缓存 | 按已有有效性与重建规则维护 | 删除后可恢复，不影响原始文件 |

真实图库验收应在副本与独立 Windows 用户/虚拟机中进行，遵循 [备份规则](../../BACKUP_SAFETY.md)：保留冷备份和异常现场，核对原件哈希、元数据与样本搜索；覆盖安装/回退、任务中断、磁盘不足、共享盘离线恢复仍需实际环境验证。数据库升级不能假定旧程序支持回退读取。

收藏夹仍通过现有全量列表接口读取，再每页渲染 60 条。数据库端分页、大库性能、签名、Mac 适配与大面板拆分未在本轮宣称完成。
