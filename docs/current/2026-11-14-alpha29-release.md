# Siftory 1.0.1-alpha.29 — 卡顿诊断测试版

> 状态：当前
> 更新日期：2026-11-14

此版本供真实 Windows 素材扫描卡顿测试，增加手动卡顿日志系统，不宣称扫描卡顿已经解决。

## 测试方法

1. 安装后进入“扫描目录”，展开“卡顿检测”，点击“开始记录”。
2. 扫描之前卡顿的目录，正常切换页面和操作窗口。遇到卡顿时可点击“标记卡顿”；完全无响应时可恢复后标记。
3. 点击“停止并导出”，保存 `Siftory-performance-时间戳.json` 供分析。取消保存后，可点击“导出已有日志”。

日志包含主进程/界面延迟、预览步骤耗时、CPU/内存和手动标记，不含图片、向量或素材路径。日志仅在本机保存，上限 20 MiB、保留 14 天。切换页面和扫描结束后仍继续记录，直到停止或退出应用。完全阻塞的时长在恢复后记录；强制结束进程只能保留已落盘的日志。

## 安装包与验证

Windows x64 在线安装包，模型及按需组件继续按原有流程下载。构建产物附带 SHA256、源码构建身份、启动和归档检查结果。打包测试新增真实日志按钮、Renderer 长任务捕获及 JSON 导出检查。

启动检查采用隔离的全新数据目录，不覆盖用户真实素材，不等于已有安装升级兼容性或真实目录建库流畅度验收。完整旧版 UI 测试结果独立保存在 `validation-status.json`，不得把诊断能力可用表述为卡顿已修复。
