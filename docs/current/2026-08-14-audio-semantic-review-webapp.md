> 日期：2026-08-14

> 状态：当前

## 启动

在项目根目录运行：

```powershell
npm.cmd run review:audio
```

终端会输出带随机访问令牌的本地地址：

```text
http://127.0.0.1:4178/audio?token=...
```

复制完整地址到浏览器；按 `Ctrl+C` 停止服务。若4178端口被占用：

```powershell
npm.cmd run review:audio -- --port=4179
```

## 页面能力

1. 只接受当前 completed 音频任务、权威manifest视频和同一generation转写三者完全匹配的数据。
2. 自动载入 `sample-a569` 约27分48秒对话视频的147个匿名语义片段，不显示真实路径和文件名。
3. 精确播放当前语音，或额外播放前后各350毫秒的上下文；浏览器使用Range请求，不复制原视频。
4. 为每个说话人标签选择最长语音作为参考声纹，便于跨片段保持判断一致。
5. 一键选择“标签正确 / 说话人错 / 边界有误 / 无法判断”，保存后自动进入下一条；支持数字键 `1–4`、空格播放和 `]` 跳到下一个未完成。
6. 转写文字默认隐藏，只用于定位；可选填写修正说话人与备注。
7. 实时汇总完成数、各类结论和可判定说话人准确率。
8. 支持脱敏汇总、完整私有备份和备份导入；脱敏汇总不含转写、备注、路径或文件名。

## 保存位置

人工记录原子保存到：

```text
%APPDATA%\floating-clock-electron\media-search\semantic\reviews\sensevoice-speaker-sample-a569-review.json
```

网页服务只监听 `127.0.0.1`，每次正常启动生成新的随机访问令牌。URL和API只接受固定匿名样本与 `turn-NN`，不能传入任意文件路径。

## 验收口径

- “标签正确”：当前声音与该speaker参考声纹一致。
- “说话人错”：能明确听出属于另一位说话人；可选填写修正标签。
- “边界有误”：起止位置截断、混入另一人或大段非语音，以致speaker结论不可靠。
- “无法判断”：声音太短、被音乐覆盖、多人重叠，或片段没有speaker标签。

147条全部给出任一结论即完成工具侧门禁；随后导出脱敏汇总并把人工结论写回VID-014记录。页面不会代替人的听觉判断，也不会自动把VID-014标记为verified。

最初网页曾指向约4分13秒的 `sample-39de`。人工试听确认该素材主要是哼唱，不适合对话与说话人验收，因此已改为语音密度更高的 `sample-a569`；旧样本记录未删除，但不再作为当前权威验收集。

2026-08-15收口时，私有记录中21条已判定样本全部为“标签正确”，另有1条未确认；用户明确接受该抽样结果并要求进入下一步。项目据此关闭VID-014抽样门禁，但保留“未完成147条逐条全审”的事实。
