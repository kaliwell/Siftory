## 安装与数据边界

Alpha 安装程序使用独立的 `com.floating-clock.electron.alpha` 标识、Siftory Alpha 产品名称和快捷方式；实际应用可执行文件仍为 Siftory.exe。这样避免自动卸载或覆盖旧稳定版安装注册。程序继续使用现有兼容用户数据目录，因此不能同时运行多个版本；升级前须退出程序并备份完整数据目录及原始素材。

安装向导、GitHub 发布说明和单独备份文档均标明 Alpha 测试状态。构建只包含 Windows 桌面程序及选定的必要组件，不包含用户素材、运行数据库、凭据、AI 模型或外部 FFmpeg 命令行工具。
