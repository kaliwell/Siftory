# 启动响应与任务抽屉优化

> 状态：当前  
> 更新日期：2026-10-26

执行身份 Codex / GPT-6，精确版本未公开；未使用子代理。任务开始时工作区干净，基线为本地 Alpha 4，未操作生产素材与应用数据。

隔离实测发现：Windows 权限加固在窗口出现前耗时约 1.3–1.6 秒，重复执行还可能触发 SeSecurityPrivilege 错误。改为每次读取真实 ACL，已符合限定 SID、完整权限及继承条件时直接通过，仅在不合规时执行修复；不使用缓存标记跳过权限核验。小型目录的 PowerShell 启动开销仍存在，不宣称该步骤已显著提速。

两套真实测试模型的同步状态校验占用主线程约 0.8 秒。对同一组本地模型进行交替测试，同步校验的最大事件循环延迟为 783、794 毫秒，异步分块校验为 15、21 毫秒。总校验耗时未缩短；改进的是校验期间的界面响应。首次进入状态 IPC 时异步完整核对 SHA256，同模型并发查询合并；不信任持久化校验侧车作为完整性证明。

增加脱敏启动阶段记录：模块加载、Electron 就绪、数据权限核验、条款检查、服务注册、窗口创建及页面加载。记录保存到实际应用数据目录的 diagnostics/startup-timing.json，仅含版本、阶段与相对耗时，不包含路径、查询或凭据。真实图库规模及机器环境的启动总耗时需要据此单独测量。

任务面板改为右侧抽屉，顶部固定标题与操作，优先展示任务状态和恢复按钮。存储统计及高级资源调度默认折叠，准备状态、健康检查和模型管理保留独立入口。内部 app-restarted 状态翻译为可读的暂停原因，隐藏无意义的内部哈希 ID；已有部分进度不足 1% 时显示小于 1%，不再误显示 0%。重启后的停止任务不会因此自动运行。

验证覆盖真实临时目录 ACL 连续核验、完整模型的异步校验及损坏检测、同模型查询合并、类型检查和工作台浏览器流程；界面检查包含宽屏与较窄窗口。具体打包与运行结果见本轮测试记录。

Alpha 5 本地包已完成资源与 NSIS 归档检查。相关回归 48 项，46 通过、2 项因平台或软链接限制跳过，无失败；打包应用在隔离配置下完成模型识别、索引保存与重启读取，原始测试图片哈希不变。一次隔离重启记录的页面加载为进程启动后 3367 毫秒，其中数据权限阶段约 2278 毫秒；这不是工作图库或所有机器的启动承诺。现有安装未被自动覆盖，未更新远程发布。
