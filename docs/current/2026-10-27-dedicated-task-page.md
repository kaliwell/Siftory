# 任务独立页面

> 状态：当前  
> 更新日期：2026-10-27

日期：2026-10-27（北京时间）。在 alpha.6 第一批诊断、进度与紧凑 UI 修复基础上，按用户要求取消任务右侧抽屉。

## 页面行为

- “任务”是主导航中的独立工作区页面，填满导航栏右侧内容区域。任务内容不再放在导航元素内，也不使用浮层定位或关闭按钮；通过主导航切换页面。
- 顶部显示任务统计，列表支持当前事项、全部任务、需要注意、已完成四种视图和手动刷新。默认展示未完成事项，保留活跃/失败优先的顺序。
- 暂停、停止、恢复、重试仍使用原任务控制接口。模型管理、搜索准备状态、健康与修复、存储统计及资源设置在列表下方按需展开，未移除功能。
- 原搜索/设置视图被隐藏而非覆盖在任务页下方；保留已挂载搜索页的查询状态。隐藏图片页不响应 Ctrl+V，隐藏综合搜索页不处理焦点快捷键和可见页刷新。后台任务继续由原主进程管理。
- 任务页路由使用非持久化工作区状态，不增加旧浮窗面板几何或可见性设置。返回原页面保留当前会话查询，窗口全局隐藏与恢复保留任务页；应用重启仍遵循原有工作区恢复规则。
- 冷加载任务页时，模型管理请求等待页面及监听器就绪后送达，避免异步模块加载导致跳转事件丢失。

## 布局

- 宽屏四个统计卡，窄屏两列；任务列表始终占据主体宽度，不固定为右侧栏。
- 使用页面主体统一滚动，取消任务列表原有 260px 高度上限和嵌套滚动。
- 明细、状态与当前项目文字至少 12px；继续使用现有主题变量。
- 页面外壳及样式按需加载，保持原首屏 CSS 和 gzip 预算，不通过放宽预算让构建通过。
