## 基线与执行归属

执行身份为 Codex / GPT-6 系列，精确版本未公开。本轮未启动子代理，未接管外部代理任务；未观察到该独立工作目录存在其他执行者写入。入口为 `docs/README.md`，基线为用户上传的 Alpha 10 源码及 [Alpha 10 测试发布记录](2026-10-27-alpha10-test-release.md)。原始上传已建立本地 Git 基线提交 `8272c87f538718b4787f84840bc38bbd283a7c84`，本轮修改单独保留，可通过交付补丁追溯。

## 已实现

- 主入口收拢为“全部素材”和“收藏夹”，取消素材库内部常驻控制侧栏及重复页签，图片网格使用完整内容宽度。
- 搜索、分类、媒体类型和仅星标采用横向筛选。标签、来源、日期、评分及已移除等条件放入“更多筛选”；保留保存筛选、排序和缩略图尺寸。
- 仅选中素材后显示收集与批量操作，可选择收藏夹或直接创建收藏夹。原有分类和引用处理功能收进“更多操作”。
- 收藏夹独立视图支持创建、浏览、名称/路径搜索、类型筛选、分页、打开原文件和所在文件夹，以及移出收藏夹。
- “从图片索引收集”复用已有索引同步能力；空状态提供收集及管理数据源入口，不增加新的文件复制导入流程。
- 审核、聚类、学习、备份、报告和分类管理移入“整理与维护”。任务进度、停止入口及存储警告仍可见。
- 调整卡片字号、行高和星标，修复未星标且未评分时卡片出现多余数字 0 的问题，适配深浅色及窄窗口。

## 交互与数据边界

继续使用已有收藏夹持久化和稳定素材身份接口，未修改数据库结构或后端实现。加入收藏夹通过现有原子批量接口完成，失败可重试；防止重复提交。收藏夹切换带请求代次保护，旧响应不会覆盖当前视图。移出收藏夹只删除对应引用，不删除原始素材；部分操作失败时保留已成功结果并提示错误。

收藏夹页面每页渲染 60 条；其列表获取仍使用原有完整列表接口。本轮不声称已解决超大收藏夹的后端分页性能。
