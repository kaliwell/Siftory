# 常规桌面窗口与现代素材工作台

> 状态：当前
> 更新日期：2026-10-22
> 所有者：Codex / root；GPT-6 系列，精确版本未公开

用户要求停止使用透明桌面 UI，改成现代软件界面。基于本地单屏修复 4af6934，窗口改为不透明、可移动、可缩放、有系统标题栏及任务栏入口的常规桌面窗口；默认不置顶。主工作台使用冷灰蓝配色，清楚区分导航、页面标题、查询、按需筛选、结果及详情。

文件所有权：本轮由 Codex/root 独占窗口创建与普通窗口可见性分支、前端工作台、导航、搜索展示、相关配置呈现、几何策略、回归与文档。素材检索、索引及存储后端不重新设计，不直接改写个人配置或用户素材。

- [x] 常规不透明窗口与单屏初始尺寸，支持拖动、缩放、最大化、关闭和任务栏。
- [x] 普通窗口禁用透明穿透与原生区域裁剪；隐藏和显示不依赖覆盖层绘制握手。
- [x] 整理导航与搜索层级，折叠高级筛选和批量操作，保留真实功能连接。
- [x] 浅色/深色、空状态/结果/详情及窄窗口截图复核。
- [x] 实际 Electron 验证尺寸、缩放、显示隐藏、沙箱、检索和原文件完整性。
- [x] 针对改动运行检查；交付同步前比对用户源码，并逐文件备份和校验。

数据源页只呈现来源登记、素材库准备和索引维护，查询统一进入搜索页。素材库保留查询与模式切换，将智能相册、扩展筛选、批量操作、同步备份工具放入可展开区域。取消主工作台透明材质和侧栏置顶/隐藏按钮，使用系统窗口控制。`Ctrl+K` 聚焦统一查询框。冷灰蓝界面支持浅色/深色与窄窗口详情。
