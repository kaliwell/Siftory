# Alpha 11 修复与测试发布

> 状态：当前  
> 更新日期：2026-10-28  
> 版本：1.0.1-alpha.11

**当前仅供 Alpha 测试。安装或升级前请退出软件，完整备份 `%APPDATA%\floating-clock-electron`，并单独备份原始图片、视频和工程文件。先使用素材副本测试，避免同时运行多个版本。索引不能代替原件备份。**

## 本次修改

- 素材库采用左右工作区，整理筛选、收藏、审核、样本搜索和维护操作。
- 优化竖屏、近方形窗口、响应式断点和操作区滚动，修复诊断被吸顶卡片遮挡及重复边框。
- 数据源按盘符分组，支持折叠、数量显示、目录自然排序和紧凑信息展示。
- 显示／隐藏默认快捷键为 Ctrl+Shift+Alt+Q，移除旧 R 绑定。支持自定义、冲突反馈、保存失败回滚及重启恢复。
- 录入期间通过主进程短期会话抑制本应用的隐藏、退出等动作，并将已注册的组合反馈给输入框；失焦、结束或会话超时后恢复动作，不释放原生注册。
- 启动和保存共用冲突校验；异常配置回退默认键并提示，避免退出键被其他动作抢占。支持 Ctrl+Tab 等修饰 Tab 组合，裸 Tab 继续用于焦点导航。
- 新增快捷键测试接入默认测试链。共享校验模块使主进程可达模块数由 315 增至 316，已在构建图预算旁记录原因；层级和其他预算检查保留。

## 验证与边界

本次修复对应 [10 月 28 日审计](../audits/2026-10-28-current-project-audit.md) 的 A01–A04。审计报告保留修复前失败证据，发布前验证结果另行记录。

回归覆盖默认键、保留键冲突、配置恢复、失败回滚、录入动作保护、会话失焦及超时、Ctrl+Tab 录入、界面布局和滚动。浏览器测试使用实际 React 页面及合成 IPC；主进程回调保护采用隔离测试，不代表对所有第三方热键工具或所有 Windows 输入法完成穷尽验证。

安装器为 Windows x64 Online 包，未数字签名，不捆绑外部 AI 模型及 FFmpeg 命令行工具。归档和独立临时配置启动检查不等于真实用户目录上的覆盖安装、回退或完整图库验收。
