# Alpha30：工程预览 Windows Shell 隔离

> 状态：部分实施
> 更新日期：2026-11-14

## 实测依据

用户提供的 Alpha29 单次日志没有丢弃记录。主进程最大定时器延迟为 3154 毫秒，Renderer 最大定时器延迟为 11.7 毫秒，可见帧间隔最大 33.4 毫秒，没有记录到 Renderer Long Task。117 次 Shell 回退累计约 109.4 秒，占已完成预览调用耗时约 80%；91 次 PSD 内嵌预览累计约 1.17 秒。系统空闲内存约 19.3 GiB。

包含 Shell 完成记录的 27 个采样窗口中，25 个出现超过 500 毫秒的主进程延迟。七次人工标记附近的主进程采样延迟均超过一秒。此证据支持优先隔离 Shell 路径，不能直接区分 createThumbnailFromPath、getFileIcon、像素比较或编码中哪一步阻塞；异步调用返回前的同步前缀计时不会覆盖 await 之后发生的同步工作。

记录结束时仍在生成预览，没有整轮建库完成或索引完整性结论。本文仅保留汇总数据，不提交用户原始日志、路径、图片或 trace 标识。

## 修改

- Electron 新启动入口先识别受 IPC 与随机 nonce 约束的辅助进程角色，再加载正常主程序。辅助角色不加载主应用服务，不申请单实例锁，不创建窗口；使用独立临时数据目录。
- 整个 Shell 路径迁移到辅助 Electron 进程，包括文件状态查询、1024 像素缩略图、large 文件图标、64 像素图标比较和 PNG 编码。保留原来的尺寸、阈值和提供器缓存版本。
- 单个串行进程复用，空闲 15 秒回收；请求总预算 15 秒。取消、超时、崩溃或非法结果均先回收所属进程，再允许重建。退出应用时取消活动和排队请求。只终止本运行时持有的 ChildProcess。
- 主进程只调度和接收有界结果。PSD 内嵌预览、SVG 等原 Worker 和 PDF 独立进程继续使用原路径。
- 日志新增 `shell-preview`，记录辅助 PID、排队/总耗时、stat/thumbnail/icon/compare/encode 分项耗时和结束状态。子步骤开始前通过 IPC 通知父进程，超时也能记录当时的活动步骤。手动测试在扫描前开启仍是推荐流程。
- Shell 暂时性进程错误采用已有预览失败/重试机制，不因取消而提交晚到结果。普通文件图标仍不作为素材内容入库。

## 验证与交付

本地 supervisor 测试覆盖辅助进程同步阻塞 500 毫秒时父进程持续响应、字节传递、进程复用、硬超时、活动/排队取消、崩溃/非法消息恢复和退出清理。提取测试覆盖尺寸、像素比较、编码字节和无预览行为；原有 PDF/工程预览取消落盘回归也需通过。

Windows 构建任务增加真实 Shell API 测试：通过同一启动入口运行辅助 Electron，验证 PNG 内容像素、进程复用和回收。安装包启动检查再通过实际缩略图 IPC 触发 PSD 回退，要求日志显示独立 PID 与正常请求完成。不能以 Node 模拟进程测试代替这些 Windows 检查。

此版本用于复测之前的真实素材目录。辅助进程可消除这条路径对宿主线程的直接阻塞，不能保证 Shell 插件自身解码更快，也不构成真实目录流畅度已验收的结论。短时增加一个 Electron 辅助进程的资源占用，空闲后释放。

完整主进程类型检查在当前云依赖环境仍有缺失模型包及既有 Worker Host 类型错误；全量文档检查仍有基线旧文档元数据问题。Windows 安装包、启动与 Shell 实测结果将另行记录。

## 用户复测

安装 Alpha30 后，先“开始记录”，再使用与 Alpha29 相同的素材库准备设置。关注原卡顿目录期间按钮、切页和窗口操作；完成后“停止并导出”，比较主进程延迟和 `shell-preview` 子步骤。无需清空已有索引。
