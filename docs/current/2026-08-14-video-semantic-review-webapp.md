## 启动

在项目根目录运行：

```powershell
npm.cmd run review:video
```

终端会输出带随机访问令牌的本地地址，例如：

```text
http://127.0.0.1:4178/?token=...
```

复制完整地址到浏览器。按 `Ctrl+C` 停止服务。如果4178端口被占用：

```powershell
npm.cmd run review:video -- --port=4179
```

## 页面能力

1. 自动载入固定20个匿名样本、v6候选结果和中心15–20秒目标片段。
2. 在视频上方突出显示模型完整摘要和搜索关键词；未生成结果时明确显示失败提示。
3. 视频默认定位到目标片段中点并显示代表画面，拿不准时可播放完整目标片段。
4. 首轮只需点击“像 / 不像”，点击后立即保存并自动进入下一条；也支持数字键 `1 / 2`。
5. 场景、人物数、事件与时间、人工OCR、幻觉等级和备注保留为可选的详细记录。
6. 导出不含自由文本的脱敏汇总，或包含人工真值的完整私有备份；完整备份可重新导入。
7. 实时汇总人工完成数、严格JSON率、像/不像和幻觉计数。

## 数据与隐私

- 服务只监听 `127.0.0.1`，每次正常启动生成新的随机访问令牌。
- API按固定匿名样本ID反查权威manifest；URL不接受文件路径。
- 页面状态不返回真实视频路径或文件名。
- 视频按浏览器Range请求流式读取，不复制原视频。
- 人工记录原子保存到：

```text
%APPDATA%\floating-clock-electron\media-search\semantic\reviews\qwen3-vl-2b-20-sample-review.json
```

- 仓库不保存人工填写的真实内容。只有用户主动下载的完整备份包含自由文本。

## 完成条件

每条记录只需选择“像”或“不像”即可完成首轮初筛。完整播放、人工场景、人物、事件和OCR不再阻塞完成；需要进一步分析的样本可以填写这些可选字段。

旧备份中的“部分一致”会保留，但不会计为新一轮初筛完成，重新选择“像 / 不像”即可。
