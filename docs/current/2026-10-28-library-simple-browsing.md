# 素材库：简约浏览与收藏

> 状态：当前
> 更新日期：2026-10-28
> 范围：素材库前端，版本保持 1.0.1-alpha.11

## 设计与操作

默认主线为搜索、浏览、收藏。移除全部素材与收藏夹视图的常驻侧栏，改为顶部轻量控制和全宽素材网格。主导航只保留全部素材、收藏夹；收集已索引图片与刷新仍直接可用。

- 搜索和仅星标直接可用；分类、媒体类型、标签、来源、日期、评分、已移除和保存筛选放入“筛选”。启用条件后显示数量与清空入口，清空同时重置保存筛选选择。
- 素材数量和排序保持可见，缩略图尺寸放入“显示”。
- 仅选中素材后显示收藏夹选择、加入、选择本页、清除选择及更多操作。新建收藏夹、星标、分类、评分与引用处理收进更多操作。
- 尚无收藏夹时，主操作直接引导新建，创建后即可加入已选素材；已有收藏夹时，新建入口收进更多操作。列表读取失败时暂停该主操作，先通过可见错误入口重试。
- 收藏夹页面保留选择收藏夹、新建、刷新及搜索，类型条件按需展开，空收藏夹引导返回全部素材收集。
- 普通素材卡和收藏夹卡减少边框及背景层次；选中状态保持清晰。打开、定位和键盘可访问的操作入口继续可用。
- 分类管理、审核、聚类、学习、备份和报告从整理与维护进入，继续使用适合专业任务的控制区。任务、停止、错误和存储警告不藏入折叠菜单。

## 实现与数据边界

复用原有查询、收藏夹和操作回调。浏览视图的控制区在页面内渲染，专业视图仍通过共享控制区渲染。没有改变数据库结构、IPC 契约、搜索算法或原始文件处理方式；移出收藏夹仍只删除引用。

## 验证

浏览器回归更新为检查默认筛选/尺寸设置折叠、控制区位于网格上方、全宽内容、深浅色与 1920/1320/946/760 宽度、展开后的空间与滚动、收藏夹创建/失败重试/筛选/移除、专业视图入口和空状态导航。真实 React 页面使用合成 IPC 数据，不能代替 Windows 原生或真实用户素材库验收。

类型、修改文件 Lint/格式、文案与架构检查按本轮实际执行结果记录。远程 Windows CI 是否通过以对应提交的 Actions 为准。未生成安装器，也未改动尚待优化的收藏夹全量读取接口。
