# Alpha 14 数据迁移进度窗口

> 状态：当前  
> 更新日期：2026-10-29  
> 执行者：Codex / GPT-6，精确小版本未知；本轮无新增代理  
> 范围：迁移进度与本地 Windows 安装包，未上传发布

此前冷启动迁移只显示静态消息框，用户无法区分正在扫描、复制还是最终校验。现在使用独立进度窗口，显示阶段、总进度、文件数、数据量、当前相对路径和已用时间，保留取消按钮。

## 行为

- 扫描期间显示不定进度条与累计发现数量，不预先猜测总量。
- 复制阶段占总进度前 50%，同时计入字节与文件完成比例，避免大量小文件尚未处理时进度已满。
- 复制完成后复查原目录，随后逐文件最终校验占 50%–99%；大文件读入时持续更新。校验读取量包含原文件和目标文件，因此总读取量为待迁移数据的两倍。
- 最后复查、确认目录与切换指针期间保持 99%，只有原子提交成功后显示 100%。这是分阶段工作量进度，不是剩余时间预测。
- Windows 任务栏同步显示进度。取消或关闭窗口会终止迁移，保留原目录与未完成副本，不发布有效目标库标记。

进度窗口启用沙箱与上下文隔离，不加载 Node、业务服务或网络资源；文件路径使用文本节点显示。消息更新节流至每 150 毫秒最多一次，阶段变化立即刷新。

冷迁移进程在 Electron ready 之前将 Chromium sessionData 指向独立临时目录，窗口使用内存分区，避免浏览器缓存改写正在校验的原目录。成功或取消后均重新启动，让正式工作区在新进程绑定正确的数据与缓存路径；失败仍先显示原库保留说明。

继续保留 Alpha 13 的原始写描述符刷盘、逐文件及最终 SHA256、ACL 保护、源指纹、库身份与路径别名检查。本轮没有再次迁移真实用户库，也没有删除旧库或失败副本。
