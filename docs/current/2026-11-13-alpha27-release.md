# Siftory 1.0.1-alpha.27

> 状态：当前

Windows x64 在线 Alpha，针对 Alpha26 扫描期间仍卡顿的反馈修正原生主线程热点。

- scanning/indexing/paused/stopping 的状态统计改为尝试获取读锁，忙时复用已有快照，不在 Electron 主线程排队等待写锁；完整路径表健康检查不再附带在扫描进度查询上。
- 原生插入全新工程预览路径时，跳过没有必要的全记录遍历。更新、相同内容重试以及删除后恢复仍保留原有语义与唯一性校验。

Windows 原生验证运行 43397548887：32 项通过。5 万条合成记录分五批写入，每批一万条耗时 119、75、74、75、73ms；该结果不代表真实图片读取、解码、NAS 访问或用户界面的端到端耗时。尚未在用户机器上确认实际卡顿已关闭。

保留 Alpha26 的工程预览 Worker、Manifest 批量保存和开发验证流程调整。完整旧版 UI 矩阵及覆盖升级的未验收范围仍单列；本版本不宣称解决所有 GPU/磁盘竞争。安装包为未签名在线 Alpha，不捆绑 AI 模型。升级前按 BACKUP_SAFETY.md 备份应用数据；源素材及索引格式不变。

最新实机反馈、PSD 目录分析与未关闭项见[扫描卡顿交接](2026-11-13-scan-stutter-handoff.md)。
