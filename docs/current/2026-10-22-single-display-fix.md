# 精简工作台单屏默认范围修复

> 状态：当前
> 更新日期：2026-10-22
> 所有者：Codex / root；GPT-6 系列，精确版本未公开
> 分支：fix/focused-single-display

用户实际启动发现单一工作台占满两块屏幕。原因是主进程、前端默认值、配置恢复和重置仍沿用浮动工作区的 all 范围。之前客户端回归显式设置 primary，未覆盖旧 all 配置。

本轮文件范围：共享显示策略、工作区拓扑、主进程初始范围、配置恢复与自动保存、设置重置、前端默认值及对应显示/浏览器/客户端回归。只修改显示范围策略；不修改用户素材或直接编辑运行中的个人配置。

- [x] 新配置默认主屏，非法范围回退主屏。
- [x] 旧 all 配置一次性迁移主屏；保留指定显示器；用户重新明确选择 all 后重启仍保留。
- [x] 设置重置恢复主屏。
- [x] 回归从旧 all 配置启动，在真实双屏环境核对实际窗口边界与主屏工作区一致。
- [x] 验证后同步回用户指定的新源码目录；不覆盖已发布的 Alpha 2 标签与附件。

共享策略记录独立迁移版本。首次恢复旧 all 时切换主屏并持久化版本，之后用户在设置明确选择 all 会正常保留，不在每次启动强制覆盖。主进程创建窗口时也默认主屏，避免前端配置恢复前先铺满两个屏幕。

验证：11 项显示与拖动几何回归、135 项工作台回归、24 项浏览器交互检查、设置测试组（含 2 项跳过）、57 项窗口可见性回归、类型、Lint、格式、文档和受检构建通过。实际 Electron 报告显示 displayCount=2、legacyAllMigratedToPrimary=true、primaryDisplayBoundsVerified=true；图片匹配与原文件完整性检查仍通过。

本轮为本地后续修复。重新运行开发启动命令即可加载；既有公开 v1.0.1-alpha.2 标签和附件保留发布时的快照，不改写。
