# Alpha 10 测试发布记录

> 状态：当前  
> 更新日期：2026-10-27

本轮按维护者要求发布当前源码与 Windows x64 Online 安装包，缩减重复验证，作为 Alpha 测试版本提供。

## 更新内容

- 简化导航，移除综合搜索和重复文件查找入口，保留图片与视频搜索。
- 整理搜索表单、任务页和数据源工具栏，Alpha 提示移至左下角版本信息。
- 修复搜索请求的忙状态、停止恢复和旧响应覆盖，以及诊断身份密钥并发初始化。
- Electron 升级到 42.11.18，更新相关依赖，CI 安全审计覆盖开发及运行依赖。

## 验证范围与已知问题

Alpha 9 基线全量验证通过；Alpha 10 已通过类型检查、受检渲染构建、原生模块构建、搜索请求生命周期浏览器回归和诊断存储定向测试。依赖更新后的 npm 审计报告为 0 个已知漏洞。

发布时原生桌面流程测试未通过：生成的近似参考图在快速搜图界面未返回预期样本，而底层 balanced 查询能够返回。原因尚未确认，不能视为所有搜索模式均已验证。维护者要求先发布当前测试版本，因此本轮不继续排查，不重复全量验证，也不执行真实用户数据或覆盖安装测试。

仅供测试。安装或升级前退出软件，完整备份 `%APPDATA%\floating-clock-electron`，并单独备份原始图片、视频和工程文件。先使用素材副本测试，避免同时运行多个版本；索引不能代替原始文件备份。

安装器未数字签名。Online 包不捆绑外部 AI 模型及 FFmpeg 命令行工具；模型下载需要用户在软件中操作。请结合 [备份规则](../../BACKUP_SAFETY.md) 评估使用及文件操作风险，检索结果可能不准确。
