## 自动执行规则

1. 每轮只领取一个可以独立验证的 `auto` 切片；实现、测试、文档和工作区复核完成后才可标记 `verified`。
2. `approval` 项必须等用户明确批准对应下载、安装、真实素材范围或许可证决策，不能被自动跳过。
3. 不读取未被用户明确选择的真实视频，不移动、重命名或删除原视频。
4. Qwen、SenseVoice和运行时未实际下载并校验前，状态必须保持 `not_installed` 或 `planned`。
5. 模型失败时保留现有元数据、DINO/CLIP和字幕检索，不返回误导性空结果。
6. 所有任务复用统一调度器的 `video-deep` GPU车道，并发默认为1。
