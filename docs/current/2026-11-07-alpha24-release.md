# Siftory v1.0.1-alpha.24

> 状态：当前  
> 更新日期：2026-11-07

Windows x64 Online Alpha 性能维护版。保留 Electron + React、搜索算法、图片质量、缓存容量、安全校验和后台任务。

## 改动

- 缩略图队列仅在新请求突发时合并等待，已经排队的后续批次连续处理，保持并发与取消边界。
- 隐藏图片/视频搜索页暂停模型状态轮询，保留事件与显式刷新；重新显示立即刷新。
- FFmpeg 状态预热先让出主线程；保留就绪等待、并发去重、配置代际校验及取消保护。
- 折叠或隐藏自动维护区块时暂停界面轮询；未保存目录选择和后台维护完成结果得到保留。
- 虚拟列表重挂载卡片时直接显示匹配路径与尺寸的缓存图片，未缓存内容继续延迟。

## 实测与限制

性能测量基于 Alpha23 基线和同功能候选源码；Alpha24 为这些改动增加独立版本标识。详细条件见 [性能对照](../../PERFORMANCE_REPORT.md)和[真实图库报告](../../PERFORMANCE_REAL_GALLERY.md)。

- 生成图片队列测试：1,000 张首次处理耗时中位数减少约 34%，重复处理减少约 77%。
- 启动 ABBA 测试：可交互中位数 1.233 → 1.199 秒；未清理系统文件缓存，不代表物理磁盘冷启动。
- 真实图库三轮对照：已缓存位置回看约 131–138 → 14ms，快速滚动中的可见预览元素就绪比例约 1.8% → 100%，无新增 IPC。
- 三种目录规模均使用正常 100 项分页，不是同时渲染一万张图片。原图及编码缩略图哈希保持一致。
- 帧率和内存下降不是本版收益：5,000 项场景 P95 帧间隔 9.7 → 13ms；工作集峰值约增加 10–25MiB。

此前四项改动的组合候选通过两小时隔离运行。后续 Renderer 缓存展示改动采用短时真实图库 A/B、生命周期和打包版验证，没有把旧长测重新标为 Alpha24 的两小时验收。

已知限制：分层样本中的八张 BMP 仍无法在现有预览链路解码；首次打开偶有发生在卡片出现前的等待；文字相关性缺少固定人工评测集。上述项目均未声称解决。

后续修复：BMP 预览问题已由 [BMP 预览解码降级路径](2026-11-10-bmp-preview-decode-fallback.md) 处理，但该修复不在 `1.0.1-alpha.24` 安装包内；本版安装包的限制描述保持原样。

## 发布附件

安装包、SHA256 和本次发布的验证摘要通过 GitHub prerelease 单独提供；源码不包含用户图库、索引、模型、原始性能采样和个人路径。此前 Alpha23 的本地候选文件不替换旧 GitHub Release 附件。

本版为未签名 Alpha。打包版隔离启动及归档验证不等同于已有用户安装覆盖升级验收。升级前按 [备份规则](../../BACKUP_SAFETY.md)备份应用数据；源文件及旧数据保留规则不变。
