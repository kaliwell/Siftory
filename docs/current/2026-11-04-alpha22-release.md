# Siftory v1.0.1-alpha.22

> 状态：当前  
> 更新日期：2026-11-04

This Alpha updates the library and maintenance workspace layouts.

- Add persistent library navigation for all assets, collections, categories and tags, review, and clusters.
- Move library filters and maintenance tools into separate right-hand drawers without shifting the gallery.
- Compact asset cards and expose sorting, thumbnail size, and page selection directly.
- Consolidate source collections and index tools under Index and maintenance; group advanced operations and simplify the expanded forms.
- Fix source refresh after relocation, the search-page source shortcut, and the Chinese source preparation description.

Validation: Online build, TypeScript, changed-component lint, and the library browser checks passed. Browser checks use synthetic IPC and cover light/dark themes, 760–1920 pixel widths, collections, classification, review navigation, and empty states. Full test suites were not rerun for this immediate publication.

The unpacked Windows application was launched successfully. Updating the existing local installation encountered access-denied errors and missing program files; installation/upgrade against an existing installation is not verified for this release.

Windows x64 Online installer; AI models are configured separately. This is an unsigned Alpha prerelease. See [backup and recovery guidance](../../BACKUP_SAFETY.md) before upgrading.
