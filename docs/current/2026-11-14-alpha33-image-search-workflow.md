# Alpha33 图片搜索工作流测试包

> 状态：当前
> 更新日期：2026-11-14

版本：`1.0.1-alpha.33`，基于 `release/alpha32`。本次提交包含以下修改：

- 窗口内容区任意位置接收本地图片拖放，自动切换到图片搜索。搜索面板尚未挂载时保留一次查询请求，避免首次拖放丢失。
- 接收浏览器拖入的图片文件、HTML 图片地址、URI 和内嵌图片数据。没有本地路径时先导入临时查询图片，再执行搜索。需要登录或有防盗链限制的地址可能失败，界面提供复制粘贴或保存到本地的替代说明。
- 网页图片导入限制输入大小、像素量、并发和缓存总量；网络请求不携带浏览器登录凭据，检查重定向目标并绑定已验证的公网 DNS 地址。
- “分步骤准备”按钮保持固定位置，展开内容位于路径列表下方，不改变目录操作和输入框的位置。
- 修正图片搜索速度单位、阶段 ETA 与搜索中空状态，增加缓存选择和阶段耗时诊断。对应 [Issue #1](https://github.com/kaliwell/Siftory/issues/1)，原始约 19 秒等待尚未复现，不能宣称性能根因已经解决。

诊断说明及测量限制见 [首次图片搜索进度与缓存诊断](2026-11-14-image-search-cold-start-diagnostics.md)。
