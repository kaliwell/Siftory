# 全界面样式统一与设置布局修复

> 状态：已替代
> 更新日期：2026-10-24
> 来源：用户提供的累计 UI 补丁

本说明保留第一轮改造记录，最终导航和设置分组以[工作流整合](2026-10-23-workspace-flow.md)为准。下文验证记录来自补丁交付方，本地合并验证另行记录。

基于 main `5446351`（1.0.1-alpha.2），本地分支 `fix/unified-interface`。

## 改动

- 设置改为六个分类入口，每次显示一个分类，保留按需挂载、自动保存与引导跳转。外观表单在桌面限宽 290px、窄窗口限宽 340px，AI 控制端口和系统操作按钮也不再拉满容器。
- 搜索、原图片搜索、素材库、数据源、视频建库、查重、索引维护与设置统一页头说明、卡片、输入控件、字号、间距和空状态；继续使用现有主题色。
- 图片与视频的桌面操作区使用限宽侧栏，窄窗口上下排列。搜索详情在窄窗口覆盖搜索区域，提供更大的可读空间。
- 索引维护直接显示管理内容，指标卡自适应换行，修复浅色模式下的固定深色背景。
- 任务抽屉修复侧栏按钮样式继承导致的标题换行，放大状态卡文字；修正视频模型加载状态与缺失模型文案。
- 设置页和共享页面样式按需加载，保留既有首屏资源预算。没有删除搜索引擎、数据维护或模型管理功能。
