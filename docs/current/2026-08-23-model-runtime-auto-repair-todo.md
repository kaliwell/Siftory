## 触发依据

- 生产提示词实测为 4797 个输入 tokens，而原低显存配置只有 4096，Ollama 在生成前直接返回 HTTP 400。
- 同一提示词使用 8192 上下文与 1024 输出预算可完成严格 JSON 解析，因此 8192 是当前已验证的首次安全档位。
- 模型在没有 OCR 证据时曾把画面单词写入摘要；原解析器只清空 visualText，其他可检索字段仍可能保留该文字。

## 自动化边界

- 上下文只在预检需要或 Ollama 明确报告上下文溢出时升级，最多经过三个固定档位，不对一般 HTTP 错误重试。
- 每个请求仍受 16384 上下文、1024 输出、响应体大小、图片大小、超时和中止信号约束。
- 输出中和只作用于没有相应文字证据的模型结果；有 OCR 证据的可见文字保持原有行为。
- 模型仍保持本机环回访问、固定模型身份核验和 keep_alive 为 0，不触发下载、拉取或外部网络访问。
