# Alpha31：扫描和预览错误采集

> 状态：部分实施
> 更新日期：2026-11-14

用户 Alpha30 截图显示扫描 idle，同时素材库准备标题为“错误”，另有 1543 个“无法读取”和工程预览失败警告。这些来自不同层级：原生扫描跳过计数、工程预览结果，以及完整准备流程（包含模型/向量阶段）。没有逐项错误原因，不能认定全是文件损坏，也不能把 idle 当作完整准备成功。

## 本次处理

- 高级界面也显示准备流程失败步骤和实际错误，避免仅有“错误”标题。
- 原“无法读取”改为“跳过文件”，保留原计数；它包含读取失败、尺寸保护、格式签名拒绝和解码失败等不同情况。
- 原生扫描新增只读分页错误接口，记录错误类别和详细原因，读取失败包含打开/读取步骤及当时的 errno/Win32 错误值，不改变解码/尺寸保护。每轮保留至多 4096 条、8 MiB 的明细，并保留所有错误类别总数，超出的样本数量明确报告。原有旋转文本日志的 200 条限制不再影响这份结构化明细。
- 自动采集工程预览、Shell 回退、输出保存、预览哈希、索引写入、目录访问及准备流程失败。Shell 不再吞掉底层错误信息，记录失败步骤、原因和 PSD 的尺寸/位深/通道等结构元数据，不记录像素。
- 扫描结束后异步排空原生明细，按小批次写盘并处理写入背压，保持 Alpha30 的 Shell 进程隔离。日志问题不能终止建库。
- 新增“扫描与预览错误日志”面板，自动记录，无需手动开始。准备完成或报错后直接导出 JSON。

## 导出与隐私

本地错误日志保存在软件数据目录 `diagnostics/scan-errors`，复用有界异步存储，20 MiB 上限、14 天保留。默认导出最近一轮扫描，按错误码/步骤汇总，文件用会话内匿名 ID 关联，不包含图片和素材路径。

若需定位具体文件，可勾选“包含本次软件会话的文件路径”。路径映射只保留在内存中，受 8192 条/8 MiB 限制；退出软件后不能恢复旧记录的路径。只导出与当前报告有关的映射。映射或错误明细被截断、存储失败或原生接口不可用时，报告提供相应信息。

错误记录是处理尝试，同一文件可在 Shell、最终预览等不同层产生多条记录，不能直接把所有记录数相加当作坏文件数。预览缺少内嵌图、系统没有对应 Shell 处理器、受保护的大图等仍需依实际日志分类处理；本版本不宣称截图中的全部 1543 个文件已恢复读取。

## 验证和复测

本地测试覆盖 1543 条失败分页排空和真实磁盘写入、零队列丢失、路径脱敏/可选映射、代际切换及无效接口保护。浏览器检查覆盖默认/含路径导出和高级模式失败原因可见。Windows 增加原生错误分页/计数/重置测试；打包启动检查通过实际扫描损坏 PNG 验证持久化，并分别导出默认脱敏和含路径报告。

安装后，用同样设置准备素材库，出现提示后展开“扫描与预览错误日志”，导出报告；若需要逐文件处理，退出软件前勾选包含路径再导出。无需清空索引，也不必重新开启卡顿记录。真实文件读取和预览成功率的修复验收，需依新日志与具体文件继续确认。

完整主进程类型检查在当前云依赖环境仍受缺失模型依赖及既有 Worker Host 类型错误影响；全量旧 UI 检查与实际安装升级验证状态以发布附带证据为准。
