# 主体选择框遮挡原图修复

> 状态：当前  
> 更新日期：2026-10-27

用户截图中的深色实心矩形来自检测框按钮的样式冲突。桌面统一按钮规则覆盖了检测框的半透明背景、边框和内边距；普通按钮的 34px 最小高度也会撑大较小的检测框。悬停规则同样存在优先级冲突。

修复将检测框规则限定为舞台内的图像选择按钮，提高到足以覆盖通用按钮规则的优先级。保留半透明填充及悬停反馈，清除按钮最小尺寸、内边距和阴影，保持检测框按图像比例定位。不修改检测模型、分割模型、原图或向量库。

验证：

- 修改前，在真实 React 工作区及完整样式下复现不透明背景：计算样式为 rgb(26, 32, 42)，透明度回归断言失败。
- 修改后，深浅色及 1320/760 窗口宽度的背景、悬停、细小检测框尺寸和点击选取均通过。
- 模拟 SAM 响应，验证显示坐标到原图坐标转换、蒙版显示、撤销/重做及搜索请求携带蒙版会话。
- 17 项坐标、预览、蒙版会话和查询裁剪测试通过；类型检查、测试脚本 lint、格式及 renderer checked build / 资源预算通过。
- 浏览器脚本：npm run test:subject-picker:browser。需要可用的 Playwright Chromium；可用 SIFTORY_TEST_CHROMIUM_PATH 指定浏览器路径。

截图使用合成图片及模拟 Electron/SAM 响应，不代表 Windows 原生客户端或真实模型精度验收。本次只解决截图所示的 UI 覆盖问题，不宣称解决此前低于 50% 裁剪检索异常。未生成安装器或推送 GitHub。
