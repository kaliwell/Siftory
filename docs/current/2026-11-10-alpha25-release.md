# Siftory v1.0.1-alpha.25

> 状态：当前  
> 更新日期：2026-11-10

Windows x64 Online Alpha 维护版。保留 Electron + React、搜索算法、图片质量、缓存容量、安全校验和后台任务。

## 改动

- 修复 BMP 预览：`sharp`（libvips）无 BMP 加载器、Electron `nativeImage` 只解 PNG/JPEG 时，CPU 预览链路降级到系统缩略图（Windows WIC / macOS）；仅 `.bmp`、`.ico` 生效，损坏文件仍返回原错误。
- 工作台界面精简：移除侧栏品牌文字与图标、「工作台」分组标题、整行页头以及「本地运行」徽标；页标题改为读屏专用。
- 间距整理：页签栏上边距 4 → 14px，内容区 22/28 → 18/24/22，侧栏顶部 16px 并去掉折叠按钮负边距。
- 应用数据位置收敛为单一可编辑入口：迁移只在 设置 → 数据与重置 发起；索引与维护页显示只读摘要并提供跳转。
- 派生数据删除入口明确边界：全库清除、按来源清理、按文件夹按层删除三种作用域互相说明并跳转；导航「数据源」改名为「扫描目录」，与维护页的来源注册区分。

## 实测与限制

- BMP：只读扫描本机活动素材目录的 995 个 BMP，其中 994 个经系统缩略图解码成功；新增真实 Electron 冒烟覆盖 24/32/8/4/1 位、OS/2 core 头与自上而下排列，并用四象限像素校验确认不是通用文件图标。
- 界面：桌面浏览器用例覆盖 1920/1320/946/760 四种宽度（93 张截图）、素材库用例与 34 组主题调色板通过；单测与文档门禁通过。
- 已知限制沿用 Alpha 24：首次打开偶有发生在卡片出现前的等待；文字相关性缺少固定人工评测集；分层样本中的部分异常图片仍可能无法解码。
- 本版未做覆盖安装升级验收，未签名，也未重新跑完整 GPU/模型矩阵。升级前按 [备份规则](../../BACKUP_SAFETY.md)备份应用数据；源文件及旧数据保留规则不变。

## 发布附件

安装包、SHA256 和本次发布的验证摘要通过 GitHub prerelease 单独提供；源码不包含用户图库、索引、模型、原始性能采样和个人路径。
