# Siftory 1.0.1-alpha.28

> 状态：候选发布；安装包及公开附件以本次成功的 GitHub Actions 运行结果为准

Windows x64 在线 Alpha，优化真实素材中的工程预览卡顿和大索引写回。

- 原生已有记录使用运行态路径定位缓存，避免每次更新反复规范化全部路径；工程扫描改用可取消的异步写回，保留记录顺序、分段格式及搜索行为。
- PDF 预览进入独立、可复用子进程，支持超时、RSS 软预算、取消和退出清理；自动扫描先处理快速预览，再处理 PDF / PDF-compatible AI。
- 自动 PDF 尝试使用 15 秒预算；显式选择源文件搜索/更新保留 120 秒重试机会。失败保留状态和旧成功预览，界面提示重试。

本地定向验证：74 项原生测试、69 项预览/退出/架构及验证路由测试通过；232 个真实 PSD 成功预览重新生成后，尺寸和内容哈希与基线一致。119,000 条内存记录、24 次变化写回的三轮中位数由 13.37 秒降至 0.065 秒。

真实目录的 387 个工程文件处理阶段由约 128 秒降至约 16.6 秒，**不包含普通 PNG 的首次扫描**。该变化包含对失败 PDF 的更短自动尝试预算；问题 PDF 仍不能成功生成预览，不代表 PDF 渲染成功率提高或所有卡顿均已解决。详情见[优化对比报告](2026-11-13-scan-stutter-optimization-report.md)。

发布门槛包括 Windows 原生回归、预览回归、资源与许可证检查、安装包归档验证，以及隔离的实际打包启动和 PDF 子进程预览。附件中的 `validation-status.json` 会单列完整旧版 UI 诊断结果；升级覆盖、全部 GPU/模型功能和长期运行尚未完成全面验收。

安装包未签名，不捆绑 AI 模型；源素材与索引格式不变。升级前按 [BACKUP_SAFETY.md](../../BACKUP_SAFETY.md) 备份数据。私人素材、缓存和性能采样不包含在安装包附件中。
