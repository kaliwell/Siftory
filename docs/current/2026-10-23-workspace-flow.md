> 状态：当前
> 更新日期：2026-10-24
> 来源：用户提供的累计 UI 补丁

下文验证记录来自补丁交付方。本地接收分支为 `feat/unified-interface-20261024`，原生验证结果及本地合并状态见[合并记录](2026-10-24-ui-patch-integration.md)。

基于 main `5446351`（1.0.1-alpha.2），分支 `fix/unified-interface`。
本轮延续同日的全界面统一改造；现代桌面设置从上轮六类调整为五类，旧浮窗布局仍保留原面板设置。

## 最终导航

| 主入口       | 内容                                                      |
| ------------ | --------------------------------------------------------- |
| 搜索         | 综合、图片、视频三个页签，共享导航与页面外观              |
| 素材库       | 已收录素材及详情                                          |
| 数据源       | 图片素材、视频素材；添加来源、准备索引和管理素材          |
| 重复文件查找 | 文件夹选择、比较、结果检查流程                            |
| 索引与维护   | 容量、索引数量、待检查项；按需展开高级工具                |
| 设置         | 外观与显示、搜索与模型、数据与重置、AI 控制、系统与快捷键 |

任务保留独立抽屉。窄窗口可收起导航为图标栏，各按钮保留可访问名称。

## 行为与兼容

- 移除图片搜索与视频建库的重复主导航入口，保留原搜索引擎和后台任务。搜索页只展示查询相关控件，来源与建库控件归入数据源。
- 搜索与数据源之间切换保留当前查询状态。视频工作区视图随偏好保存；旧版本未记录视图的配置默认进入视频素材准备页。没有新增跨重启保存查询内容的承诺。
- 设置整体限宽，表单按窗口宽度调整；现代桌面隐藏仅适用于旧浮窗布局的选项和快捷键说明。保存中、已保存、失败重试状态来自真实设置写入状态。
- 任务优先显示进行中和失败项，完成历史默认收起；准备状态与模型信息可展开查看。
- 缺少语义索引显示为“尚未准备”，不计为数据损坏。详细索引统计与高级记录工具默认折叠，展开后才读取相应详细记录。
- 图片与视频空状态区分未准备素材、可以开始查询、查询后没有结果。查重页面补充操作步骤。
- 共享样式继续按需加载，保持现有主题和资源预算。

## 验证结果

- TypeScript 类型检查通过；修改范围内 ESLint 无错误和警告。
- focused-workspace 153 项、settings 82 项、architecture 20 项、i18n 7 项、readiness 20 项均通过。
- focused-workspace 浏览器回归 24 项通过，无页面异常。
- modern-desktop 浏览器回归通过：三种图片搜索引擎调用、查询在视图间保留、视频视图持久化、设置保存失败重试、任务历史与失败优先、维护记录延迟读取、导航折叠。
- 设置布局检查覆盖 1920、1440、1000、760px，详情布局检查覆盖 1320、1000、760px；主要页面包含窄窗口和深浅色截图，共 34 张。
- `build:renderer:checked` 完成，资源预算与构建来源检查通过；首屏 CSS 为 52,209 字节，gzip 9,871 字节。
- 累计补丁以 `5446351` 为基线，包含本轮与上一轮 UI 修改；交付前用临时 Git 索引检查补丁可应用性。

## 复现与验证边界

设置 `SIFTORY_TEST_CHROMIUM_PATH` 指向可用 Chromium，然后运行 `npm run test:modern-desktop:browser`。`SIFTORY_UI_SCREENSHOT_DIR` 可指定截图输出位置。

截图来自真实 React App 与合成 Electron bridge，素材、数量和任务为测试数据。没有验证 Windows Electron 原生窗口、原生扫描、真实模型推理或 Windows 安装包，也没有推送 GitHub 或部署 VPS。

运行环境为 Node 24.19.0 / npm 11.9.0，与仓库固定版本不同；未更改仓库版本要求。依赖安装跳过生命周期脚本，未下载模型或 Electron 原生程序。验证后清理本轮临时依赖、浏览器与构建产物。
