# 共享目录增量索引与历史记录去重

> 状态：当前  
> 更新日期：2026-10-29

## 触发与修改

本轮处理共享目录反复更新时的重复工作、路径别名和记录统计。修复前的 Windows 复现分支中，同一个 UNC 文件的常规路径与 extended UNC 路径会形成两条记录。

- Native 将 extended UNC / extended drive 路径、分隔符、路径中的点段和大小写统一到同一索引键；扫描内去重使用该键，不再使用原始拼写。
- 分片清单按新到旧加载。同步加载采用与异步加载相同的校验读取器，使用新的路径映射后再整体发布，旧分片不覆盖新分片的文件大小、修改时间与记录归属。
- 路径映射保留最新分片及行号。历史重复版本在进入搜索 topK 之前排除，避免旧版本占用结果名额；旧分片字节保持不变。
- 重复提交相同的元数据与图像哈希不会再次产生 dirty 状态或追加版本。已有记录查询直接使用路径映射定位，查找不存在的原始工程路径不再遍历整库。
- 记录数按当前有效路径统计；物理存储记录单独显示。映射健康状态不再按“唯一路径数 / 历史物理行数”的 95% 比率误报。
- 工程预览阶段接收扫描模式。“仅添加新文件”跳过已索引并保留有效预览的来源；“更新”复用未变更的已有预览，变更时替换旧记录并使相关来源向量失效。预览缓存存在但 Native 索引缺失时仍会补建。
- 工程目录枚举合并重叠目录。应用数据迁移后，工程预览的 Native 历史缓存路径可以继续匹配；预览确实变化时清理对应旧路径别名，避免复制一套索引关联。

## 验证

新增 Native 回归覆盖 UNC 等价路径、追加版本的逻辑计数、保存/重载后的最新元数据、目录后端重复更新、重叠扫描根、相同 upsert 幂等性，以及带重复别名的旧版不可变分片与 topK。工程预览回归覆盖重复扫描、源文件修改、补建缺失索引和迁移后的历史路径复用。

Windows CI 增加 Native 编译与索引/搜索回归，并在原有源码、219 项核心行为和四组浏览器检查旁运行相关工程预览用例。托管 runner 的 USN 权限与缩略图压力工作负载不同于普通桌面，完整硬件工作负载仍通过原有 Native 验收运行；新增 job 针对索引存储、路径、清单、搜索与相关扫描合同。

## 边界

本次没有访问用户的实际 NAS，自动测试采用 Windows 目录后端及合成 UNC 路径。盘符映射与 UNC 指向同一共享、不同服务器别名或不同路径下内容相同的文件，不会仅凭相似内容自动合并。本轮保留现有分片格式和原始媒体，历史物理记录可由已有压实功能回收。

本地使用时需要从最新源码重新编译 Native 模块；安装包构建脚本会执行该步骤。数据目录迁移已经在此前提交中完成，其库编号、位置引导及回退规则继续适用。
