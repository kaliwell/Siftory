# Alpha 工作环境测试：建库进度与模型安装

> 状态：当前  
> 更新日期：2026-10-26

执行身份为 Codex / GPT-6，精确版本未公开；未使用子代理。开始时工作区干净，基线为已发布 Alpha 3。只操作开发工作区和隔离测试数据，不修改工作环境的原始素材或真实模型。

本轮修正扫描仍在枚举时以“已索引数 + 当前待处理数”作为最终总数、从而显示 100% 的问题。扫描期间使用不确定进度和已处理数量，保存完成后才显示完成；尚未落盘的任务不再宣称重启后恢复。

模型下载使用 Electron 网络栈以支持系统代理，保留 SHA256 与完整必需文件验证。下载失败原因不再被下一次查询覆盖成“未安装”。任务中心订阅模型状态事件，下载完成后立即更新，旧轮询结果不能覆盖较新的事件。图片页在重新获得焦点和定时检查时重新核对模型。

新增经用户点击确认的一次性模型准备入口，依次下载并校验 DINOv2、CLIP。复用已校验的文件，修复只补齐缺失或损坏文件；任何下载或校验失败都会中止后续准备并显示原因。不会启动时静默下载模型，也不自动下载外部视频和音频模型。

工作台显示“Alpha 版本仅用于测试、先备份应用数据和原始文件、自行评估使用及文件操作风险、检索结果可能不准确”的提示。该提示描述实际测试边界，不承诺能够免除一切责任。

验证覆盖任务投影、模型下载失败及恢复、完整文件校验、代理网络入口选择、自动准备顺序与复用、界面事件刷新及构建。实际完成结果以本轮测试日志与后续更新为准，模拟下载不能替代工作网络中的真实下载验收。

本轮完成 29 项相关回归、18 项界面协议和防护检查；模型准备界面与工作台浏览器检查无页面错误。使用隔离临时配置和 Electron 网络栈实际下载 DINOv2 与 CLIP 全部必需文件，均通过固定大小、SHA256 校验及服务重启识别。另以隔离配置运行打包后的程序，确认两套真实下载模型可识别、生成的图片索引可保存并在重启后读取、原始测试图片哈希不变。
