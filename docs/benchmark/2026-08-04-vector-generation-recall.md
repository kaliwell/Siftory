## 解释

- 自查询 top-1 比例为 0.88/0.91，但 top-1 分数差最大仅 1e-10 量级：所有"未居首位"
  都是与完全重复/近重复向量的**精确平分**，不是排序错误。门禁据此采用
  "自查询在 top-K + top-1 分数差"口径，而不是朴素的 top-1 命中率。

  对照：generation F16 文件转 F32 后同样精确扫描；路径按 generation 顺序对齐。

  本次以真实数据校准后维持 recall@50 ≥ 0.99、self-in-top-K ≥ 0.995、
  top1 gap ≤ 1e-3、误差中位 ≤ 1e-3、p99 ≤ 5e-3。
