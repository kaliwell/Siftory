# PREP-007 Image Search Q8 投影 ANN 验证

> 状态：已验证  
> 日期：2026-08-22  
> 范围：DINO 全局向量的 Image Search 候选召回与精确重排  
> 权威产物：`artifacts/benchmark/vector-ann-prep007/latest.json`

## 结论

PREP-007 已通过真实性能、搜索质量和源数据只读门禁，并默认进入既有 ANN worker 热查询路径。44 万条真实 DINO 向量上的 50 个分层样本连续三轮均把候选比例由旧方案约 65%–91% 收敛到 20%，平均 Recall@50 为 99.88%，最差为 98%，查询图首位一致率为 100%。热查询 P95 三轮改善 83.04%–84.08%。

该变化只替换候选生成器：最终排序仍读取候选的原始 Float16 768 维向量做精确点积；ANN 不可用、损坏、过期、结果不足或 worker 失败时，`vectorIndexService` 仍执行完整 Float16 精确扫描。

## 实现

1. 从 768 维 DINO 向量中以固定种子选择 128 个互不重复维度，保证不同进程和重建结果一致。
2. 全量加载时按每个投影维度的绝对最大值建立独立比例尺，把投影保存为有符号 Q8 内存视图。当前 440,450 行投影本体为 56,377,600 字节，约 53.77 MiB。
3. 查询先构造最新有效行和授权 scope，再对 Q8 投影打分；全库候选最多为 active set 的 20%。小作用域会优先保留至少足以满足请求的 `topK`，不会为了比例门槛返回不足结果。
4. 分数阈值相同的候选按稳定行序补齐，随后继续使用原有 Float16 精确重排和确定性行号 tie-break。
5. committed delta 热追加只读取新增向量并追加一个投影段。若新增值超出旧比例尺，追加在任何派生签名提交前失败并转为完整安全重建，避免静默 Q8 clipping。
6. 原有 v1 SimHash 文件格式、完整性证明和重建逻辑保留，未迁移或改写用户向量缓存；这样可以安全回退，也不使旧派生索引失效。

Q8 投影当前按向量 generation 在 worker 内存中重建，不单独持久化。真实隔离预热墙钟三轮为 3,777.70–3,960.40 ms；该数字包含载入 676,531,200 字节 Float16 快照、路径、既有派生签名检查和 Q8 构建。预热后查询不再读取向量文件，报告中每次热查询的 `vectorBytesRead` 和 `pathBytesRead` 均为 0。

## 方案筛选

实现前使用同一真实缓存做了只读、去标识化候选剖析：

- 单表 48-bit sparse SimHash 在候选压到 5%–20% 时，困难样本 Recall@50 仅约 50%–74%；满足质量的阈值仍需约 34%–61% 候选。
- 2–4 个独立 SimHash 表和按全库均值居中的投影仍未同时满足最差召回与候选上限。
- 64/128/256 个原始维度的低维精确投影，以及 64/128 维 Q8 投影，在探索样本的 5%–20% 候选上均达到完整 Recall@50。最终选择 128 维 Q8，在质量余量、53.77 MiB 内存和每次查询计算量之间取中间值。

因此没有继续叠加 LSH 表或放宽探测半径。探索工具保留在 `tests/vector-ann-candidate-profile.cjs`，但不作为生产门禁；正式判定只使用生产 worker。

## 回归与安全覆盖

- `npm.cmd run test:vector-ann`：40/40 通过，覆盖投影确定性、候选上限、分段/热追加一致性、scope 先过滤、取消、完整性证明、缺失/损坏派生索引重建、generation 变化、增量 I/O、预热和精确回退静态契约。
- 超出旧量化比例尺的追加向量会拒绝热追加并走完整重建；测试确认不会静默截断。
- 候选生成每 1,024 行检查取消；worker host 保留抢占、任务取消和空闲释放语义。
- 正式报告未记录原始绝对路径，且前后源快照一致；临时目录只有在解析后确认位于系统临时目录并带固定前缀时才递归清理。

## 边界

1. 20% 是当前 DINO 真实库和质量门禁下的保守默认值，不应在没有新 Recall 报告时继续下调。
2. `Float32Array.sort()` 的阈值选择本身不能中途取消，但其时间远短于完整打分；前后的长循环均支持协作取消。
3. 冷 worker 仍需载入 Float16 快照并重建内存投影；生产预热调度会按 generation 去重，前台搜索可以抢占预热。
4. 本报告验证 DINO Image Search。NekoSearch 的分类、正负样本和 active filter 语义需在 PREP-008 独立接入并重新跑人工标注质量门禁，不能直接把本报告视为其验收结果。
