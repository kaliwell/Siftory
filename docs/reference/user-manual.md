## 1. 产品简介

Siftory（寻藏）是一个面向 Windows 的本地优先 AI 媒体搜索与素材管理桌面工作区。它把时钟、快捷方式、提示词、文件管理、图片与视频搜索、素材分类、重复文件分析、应用占用分析和 SSH/SFTP 工具组合在同一个可拖动面板系统中。

主要能力包括：

- 桌面时钟、日期显示和多主题透明界面。
- 文件夹快捷方式、提示词复制与编辑、计算器。
- 多窗格文件管理、收藏路径、复制、移动、重命名和回收站删除。
- 基于图片哈希、CLIP、DINOv2、颜色和形状特征的图片检索。
- 视频扫描、抽帧、帧向量构建、文本/图片多模态检索、命中导航和 MP4/EDL/FCPXML 片段导出。
- 素材分类、标签、参考图、AI 建议、聚类、相似结果和备份恢复。
- 完全重复文件与大文件分析。
- 根据图片视觉特征恢复批量改名后的文件名。
- 已安装应用及其安装目录、数据目录和缓存目录的占用分析。
- SSH 终端、服务器状态采集、SFTP 浏览和上传下载。

本软件会读取用户主动选择的目录，并在应用数据目录建立索引、缩略图、向量和元数据。搜索和分析操作不会自动删除源文件；会改变文件或元数据的功能会在本说明书中单独标注。

## 2. 安装、启动与退出

### 2.1 系统与空间

- 支持平台：Windows x64。
- 安装程序为 NSIS 用户级安装包，可选择安装目录并创建桌面快捷方式。
- 当前发行候选采用 Online 配置，包含 Electron 和原生扫描模块，不包含模型权重。模型由用户自行下载或在使用相应功能时另行获取；具体工具范围以安装包资源清单和检测结果为准，不以固定安装包大小判断完整性。
- 图片索引、视频帧、缩略图和向量缓存会继续占用磁盘。大型素材库使用前应预留足够空间。
- GPU 加速不是必需条件。没有可用 GPU 后端时，相关任务会使用 CPU 或按界面提示回退。

当前安装程序未进行数字签名。如果 Windows SmartScreen 显示未知发布者，请先核对安装包来源和 SHA-256，再决定是否运行。

### 2.2 安装

1. 运行 `Siftory Online Setup 1.0.0.exe`。
2. 按安装向导选择安装目录。
3. 完成安装后，通过桌面快捷方式 `Siftory` 或开始菜单启动。
4. 应用使用单实例模式。重复启动通常会唤醒已经运行的窗口，而不会建立第二套独立工作区。

### 2.3 正常退出

可以使用以下任一方式退出：

- 在 `Settings > System` 点击 `Quit`。
- 按 `Shift+Escape`。
- 使用 Windows 正常关闭应用。

不要在扫描、建库、备份恢复或文件传输过程中强制结束进程。需要中止任务时，优先点击对应面板的 `Stop`，等待状态停止后再退出。

## 3. 首次启动与默认布局

正式用户协议随版本提供时，启动会先显示全文。阅读后勾选“我已阅读并同意以上条款”，再选择“同意并继续”；选择“拒绝并退出”或关闭协议窗口会退出软件。条款更新时会重新提示；同意记录只保存在本机，保存失败时会提示重试。当前内部审查版尚未发布正式协议。

新配置首次启动以 `Unified Search`（统一搜索）作为主要搜索界面，并保留 `Settings`（设置）入口。导航栏提供来源、准备状态、模型和各专项工具入口；首次引导可跳过并重新打开。已自定义的工作区会保留原有布局。

`Settings` 是工作区的固定入口：

- 默认开启。
- 在 `Settings > Layout` 中保持选中。
- 不能通过面板列表取消。
- 启动时即使旧配置曾记录为关闭，也会恢复为开启。

其他工具面板可从导航栏或 `Settings > Layout` 中开启。

软件会持续保存面板位置、尺寸、主题、透明度、语言和面板可见状态。正常重启后会恢复上次使用状态；首次安装、重置配置或配置丢失时使用代码内置默认值。

## 4. 通用窗口与面板操作

### 4.1 拖动、缩放和层级

- 拖动面板标题栏可以移动面板。
- 拖动面板右下角可以调整尺寸。
- 标题栏的“置后”按钮可把当前面板送到其他面板后面。
- 标题栏的位置锁按钮可锁定当前面板位置。锁定后，该面板不会被拖动或自动排列改变位置。
- 点击面板会把它带到当前面板层级前方。

面板拖到桌面边缘时，应用会限制交互边界，避免拖动原生透明窗口背景导致面板与窗口边界错位。

### 4.2 窗口置顶

标题栏的图钉按钮控制整个 Siftory 原生窗口：

- `Keep window on top`：保持在其他普通窗口之上。
- `Stop keeping window on top`：取消置顶。

置顶状态是原生窗口级状态，不是单个面板状态。任意面板上的图钉按钮显示并控制同一个窗口置顶状态。

### 4.3 自动排列

在 `Settings > Layout` 中可以选择：

- `Row`：横向排列可见面板。
- `Grid`：网格排列可见面板。
- `Column`：纵向排列可见面板。
- `Linked Move`：拖动一个面板时联动移动其他面板。
- `Snap to Grid`：移动或排列时吸附到网格。

位置已锁定的面板不会按普通面板方式参加位置调整。自动排列前建议先确认哪些面板已锁定。

### 4.4 面板开关分组

`Settings > Layout` 的面板开关分为两组。

搜索面板：

- `Image Search`
- `Media Search`
- `Asset Library`

其他面板：

- `Clock`
- `Folders`
- `Prompts`
- `Settings`（固定开启，不能取消）
- `Calculator`
- `File Manager`
- `App Storage`
- `Remote Terminal`
- `Duplicate Finder`
- `Batch Rename`

开启面板时，软件会尝试把新面板放入当前工作区可用位置并将其带到前方。

### 4.5 全局快捷键

| 快捷键             | 功能                           |
| ------------------ | ------------------------------ |
| `Ctrl+Shift+Alt+R` | 隐藏或恢复工作区（主快捷键）   |
| `Ctrl+Shift+Alt+Q` | 隐藏或恢复工作区（兼容快捷键） |
| `Ctrl+Shift+Alt+P` | 将面板吸附回屏幕工作区         |
| `Ctrl+Shift+Alt+S` | 显示全部面板                   |
| `Shift+Alt+Q`      | 横向排列                       |
| `Shift+Alt+W`      | 网格排列                       |
| `Shift+Alt+E`      | 纵向排列                       |
| `Shift+Escape`     | 退出应用                       |

快捷键可在 `Settings > System` 注册或注销。如果快捷键被其他软件占用，界面会显示注册失败提示。

## 5. Settings 设置

### 5.1 Appearance 外观

`Language`：

- `Chinese`：简体中文界面。
- `English`：英文界面。
- 切换后立即更新已支持翻译的界面。

`Theme`：

- `Matrix`
- `Midnight`
- `Amber`
- `Frost`
- `Rose`
- `Mono`

可以用左右按钮切换，也可以直接点击主题样式预览。

`Date`：

- 控制时钟面板是否显示日期。

`Alpha`：

- 调整面板透明度。
- 透明度过高可能降低文字可读性；看不清时可回到 Settings 调低数值。

`Font`：

- 按预设档位放大或缩小界面字体。

### 5.2 Layout 布局

布局区包括自动排列、联动移动、网格吸附和全部面板开关。`Settings` 开关为禁用状态，这是为了始终保留配置入口。

### 5.3 Vector / Rerank 向量与重排

`Vector Retrieval`：

- 控制搜索是否使用向量检索能力。

`Rerank (Color + Shape)`：

- 在向量候选基础上使用颜色和形状特征重新排序。

`Backend`：

- `CPU`：兼容性优先。
- `GPU (DirectML)`：Windows 上优先使用 ONNX Runtime DirectML；不可用时按运行时能力回退。

`Jobs`：

- 控制并行任务数量。
- 更高数值可能提高构建速度，也会增加 CPU、GPU 和内存压力。

`Text encoder`：

- `Auto`：中日韩文字查询自动路由到多语言编码器，其他查询使用英文编码器。
- `Multilingual`：始终使用多语言文本编码器。
- `English only`：只使用英文文本编码器。

中英文搜索结果差异明显时，优先检查这里的编码器模式，再确认对应模型已可用。

### 5.4 Data 数据

`Open Config Folder`：

- 打开当前用户的 Siftory 数据目录。
- 该目录包含设置、索引、缓存、素材库、远程终端配置等数据。

`Reset Sizes`：

- 把各面板尺寸恢复为当前版本内置默认值。
- 不删除快捷方式、提示词、搜索索引或素材库。

`Reset Config`：

- 恢复主题、透明度、字体、面板默认状态等配置。
- 删除用户创建的快捷方式与提示词配置并恢复默认内容。
- 确认框明确提示该操作不可撤销。
- 执行前应备份 `clock_config.json` 和 `floating_clock_settings.json`。

### 5.5 System 系统

- 显示全部全局快捷键。
- `Register Hotkeys` / `Unregister Hotkeys`：注册或注销全局快捷键。
- `Third-party licenses`（第三方许可）：打开随软件提供的许可与声明文件夹。若提示目录不可用，应恢复完整应用文件后重试；打开失败时可再次尝试。
- `User agreement`（用户协议）：只读查看当前随包协议。查看不会重新签署或修改同意记录；未发布正式协议的审查版会明确提示。
- `Quit`：退出应用。

## 6. Clock 时钟

Clock 面板显示当前时间，并可按 Settings 中的 `Date` 设置显示或隐藏日期。

常用操作：

- 在 `Settings > Layout > Other panels` 开启 Clock。
- 通过 Settings 调整主题、字体和透明度。
- 拖动标题栏改变位置，拖动右下角改变尺寸。

Clock 保留紧凑尺寸，不使用大型工具面板的默认尺寸。

## 7. Folders 快捷方式

Folders 用于按标签页管理常用文件、文件夹和可由系统打开的路径。

### 7.1 标签页

- 点击 `+` 创建标签页。
- 标签页可重命名和删除。
- 没有标签页时，先创建标签页才能添加快捷方式。

### 7.2 添加快捷方式

1. 点击 `Add Shortcut`。
2. 填写 `Name`。
3. 填写 `Path`，或点击 `Browse` 选择路径。
4. 点击 `Add`。

### 7.3 使用与管理

- 点击快捷方式打开目标。
- 右键快捷方式可选择 `Open`、`Rename`、`Change Path...` 或 `Delete`。
- 路径移动后，使用 `Change Path...` 更新目标。

快捷方式配置保存在 `clock_config.json`。删除标签页或重置配置前建议备份。

## 8. Prompts 提示词

Prompts 用于分类保存并快速复制常用文本。

### 8.1 标签页与提示词

- 点击 `+` 创建提示词标签页。
- 点击 `Add Prompt`，填写 `Name` 和 `Text`。
- 点击提示词可复制文本到剪贴板。
- 长按提示词可进入编辑。
- 右键菜单提供 `Edit`、`Rename`、`Copy` 和 `Delete`。

### 8.2 编辑窗口

编辑窗口支持：

- 修改长文本内容。
- `Ctrl+滚轮` 调整编辑内容缩放。
- 保存或关闭时按当前实现同步内容。

提示词同样保存在 `clock_config.json`。`Reset Config` 会清除用户快捷方式和提示词，因此应提前备份。

## 9. Calculator 计算器

Calculator 提供基本数字、小数、括号和运算输入。

- 可以点击面板按键输入。
- 面板聚焦时可使用键盘数字和常见运算键。
- 表达式由受限计算逻辑处理，不执行任意系统代码。

## 10. File Manager 文件管理器

File Manager 支持多窗格、多标签页、收藏路径、缩略图、排序、分组和常见文件操作。

### 10.1 导航

- 使用标签页在同一窗格打开多个位置。
- `↑` 返回上级目录。
- `Refresh` 刷新。
- `Browse` 选择目录。
- 点击路径栏可直接编辑路径。
- Quick Access 可添加常用路径；右键收藏项选择 `Remove`。

### 10.2 视图与筛选

- `Layout` 切换文件管理器布局。
- `Zoom out` / `Zoom in` 调整项目显示大小。
- `Hidden` 显示或隐藏隐藏文件。
- `View` 切换视图。
- `Group` 可按名称、类型、大小或修改时间分组。
- 列表可按 `Name`、`Type`、`Size`、`Modified` 排序。
- 点击 `Size` 时会按当时已经显示的大小生成稳定排序快照；随后到达的文件夹扫描进度和完成结果只更新大小文字与合计，不会把正在浏览或框选的行重新排走。再次点击 `Size` 才会使用最新显示值重新排序并切换升降序。
- 文件大小会直接显示；文件夹大小在项目进入可视区域后异步计算，不会阻塞目录首屏。
- 文件夹大小显示 `…` 表示大型目录中等待进入可视区域，`排队中` 表示等待扫描名额；扫描时持续显示 `≥ 当前累计大小`，悬停可查看已处理项目数；扫描完成后仍有 `≥` 表示受扫描上限或访问权限影响的不完整统计，`—` 表示无法读取。
- 切换目录、刷新或关闭面板会取消过期的文件夹大小任务；统计按文件逻辑字节计算，并跳过符号链接和目录联接。
- 已完成扫描会缓存较浅的子目录统计；进入下一层目录时通常无需重新从零遍历。文件或目录变更只失效相关路径分支的缓存。
- 路径栏的“统计合计”会将当前显示的普通文件和文件夹大小相加，并在未结束时显示文件夹处理进度；显示 `≥` 时表示仍有项目待加载、文件夹待统计或只能取得不完整下限，去掉 `≥` 后才是当前显示项目的精确综合大小。
- 位于 `C:\`、`D:\` 或网络共享根目录时，大小汇总栏会同时显示“统计合计”和操作系统统计的“磁盘已用 / 总容量 · 可用空间”。实际磁盘已用空间包含系统保留与受保护区域，因此可能明显大于可枚举文件的逻辑合计。

### 10.3 选择与快捷操作

- `Ctrl+A`：选择当前活动窗格中的全部项目。
- `F2`：重命名当前项目。
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V`：复制、剪切、粘贴。
- 可使用多选后批量复制、移动或删除。

### 10.4 右键菜单

文件或目录：

- `Open`
- `Copy`
- `Cut`
- `Rename`
- `Delete`
- `Show in Explorer`

空白处：

- `New Folder`
- `Paste`
- `Refresh`
- `Choose Folder...`
- `Open in Explorer`

### 10.5 删除与冲突

- 删除操作会显示确认框。
- 当前实现把文件移动到 Windows 回收站。
- 复制或移动遇到同名目标时，会显示冲突处理对话框。

操作大量文件前仍建议备份。网络盘、只读目录、权限受限目录或被其他程序占用的文件可能导致部分操作失败。

## 11. Image Search 图片搜索

Image Search 用于建立本地图片索引，然后进行以图搜图、文件名过滤、文本语义搜索和主体搜索。

### 11.1 建库前准备

1. 点击 `+ Folders` 选择一个或多个图片目录，或点击 `+ Drive` 选择磁盘。
2. 也可以在路径输入框手动输入目录并点击 `Add`。
3. 路径列表最多保存 64 项。
4. 选择整个磁盘时，软件会显示整盘扫描确认。
5. 建议先用较小目录验证流程，再扩大到整盘。

整盘扫描会显著增加扫描时间、索引大小、缩略图数量和磁盘占用。

### 11.2 Simple 简单模式

简单模式显示 `Prepare Library`。该流程会按需执行：

1. 扫描图片。
2. 构建缺失的 DINO 和 CLIP 向量。
3. 构建向量索引。

任务运行时可点击 `Stop`。停止后已经完成并安全写入的阶段通常可在下次继续复用。

### 11.3 Advanced 高级模式

高级模式提供独立控制：

- `Start Scan`
- `Stop`
- 扫描模式：
  - `Add New`：只添加新文件。
  - `Update`：更新变化的文件。
  - `Update All`：重新检查全部文件。
- `Native thumbs`：扫描时复用原生解码流程，为新增或变化图片构建 JPEG 缩略图。

高级搜索参数：

- `Threshold`：最低匹配阈值。
- `Top`：最大结果数，支持 20 至 1000。
- `Sort`：按分数、距离、文件大小或分辨率排序。
- `Search`：
  - `Fast`：速度优先。
  - `Standard`：平衡模式。
  - `Precise`：准确率优先，通常开销更高。
- `Scores`：显示扩展评分信息。

### 11.4 以图搜图

查询图来源：

- 点击 `Query` 选择图片。
- 点击 `Paste` 读取剪贴板图片。
- 在面板中拖放图片。
- 点击搜索结果的 `Similar`，把该结果作为下一张查询图。

`Refresh` 使用当前查询条件重新搜索，`Clear` 清除查询图。

可在 `Filter by name` 中附加文件名过滤条件。

### 11.5 文本语义搜索

1. 在语义输入框输入描述，例如“红色截图”“手机”“头像”。
2. 点击 `Semantic` 或按 Enter。
3. 中文查询建议把 `Settings > Vector / Rerank > Text encoder` 设为 `Auto` 或 `Multilingual`。

文本语义搜索依赖 CLIP 文本/图片向量。没有相应向量或模型时，应先完成 `Prepare Library`。

### 11.6 搜索结果操作

每个结果支持：

- `Open`：打开文件。
- `Folder`：在资源管理器中显示文件。
- `Copy`：复制完整路径。
- `Similar`：以该图片继续相似搜索。
- `Subject`：按图片中的主体进行搜索。
- 可把结果卡直接拖到支持 Windows 原生文件拖放的应用。普通拖动对 WebP、AVIF、SVG、AI、PDF 等旧版 Photoshop 兼容性较差的格式优先使用可见内容的 PNG/项目预览，不修改源文件；按住 Shift 开始拖动会强制传递原始文件。JPG、PNG、TIFF、PSD 和 PSB 等格式默认传递原文件。

兼容预览只保存在有界缓存中；生成失败时会退回原始文件。需要保留矢量、图层、页面或原始格式语义时，应按住 Shift 拖动或使用 `Open` / `Folder` 操作源文件。

### 11.7 Subject 主体搜索

点击 `Subject` 后：

1. 软件检测候选主体并在图片上显示边框。
2. 点击一个主体，或选择 `Auto (largest)` 使用最大主体。
3. 也可以通过区域分割结果选择 `Search this region`。
4. 主体搜索使用裁剪区域与 DINOv2 等特征寻找外观相近主体。

首次对图片执行分割可能更慢。主体不明显、遮挡严重或检测不到时，可改用整图 `Similar`。
未在 `Settings > Model Platform` 安装兼容的分割编码器/解码器时，加选和减选不可用，
但“框选”会自动退化为矩形裁剪搜索，不需要绕过模型许可证确认。

### 11.8 数据编辑与缩略图重建

数据管理功能可用于：

- 查看索引记录。
- 重新读取源图片并重算哈希。
- 修复已移动但字节大小一致的源路径。
- 删除索引记录；该操作不删除源图片。
- 重建优化缩略图。

缩略图重建后端包括原生 C++、CUDA/nvJPEG 优先、自适应、GPU 优先和 CPU 模式。CUDA 模式需要兼容的 CUDA Toolkit 与 nvJPEG 运行时；不可用时应选择 CPU 或 Auto。

不要在扫描、重建缩略图或保存索引时手工修改索引文件。

## 12. Media Search 媒体搜索

Media Search 对视频进行扫描、抽帧、向量构建，并支持图片、文字或混合条件搜索视频帧。

### 12.1 添加视频范围

- `Select Videos`：选择视频或目录。
- `+ Drive`：添加整盘范围。
- 手动输入目录或视频路径后点击 `Add`。
- `Clear Paths`：清除当前扫描范围。

### 12.2 Simple 简单模式

`Prepare Library` 会依次：

1. 扫描视频。
2. 提取搜索帧。
3. 构建缺失的 DINO 和 CLIP 帧向量。

准备完成后再执行图片或文本搜索。运行中可点击 `Stop`。

### 12.3 Advanced 高级模式

高级模式提供：

- `FFmpeg Dir`：指定 FFmpeg 工具目录。
- `Tools`：打开工具目录。
- `Clear FF`：清除自定义 FFmpeg 路径。
- `Clear Temp`：清理临时缓存。
- `Clear Video Data`：清除视频清单、帧、帧索引以及旧的 CLIP/DINO 帧向量。
- `Scan`：扫描视频。
- `Load Data`：手动加载完整清单和向量覆盖情况；大库可能需要数秒。
- `Build Frames`：抽取视频帧。
- `DINO Frames`：构建 DINO 帧向量。
- `CLIP Frames`：构建 CLIP 帧向量。

`Clear Video Data` 是破坏性缓存操作。它不会删除原始视频，但会删除已经生成的数据，之后需要重新扫描、抽帧和建向量。

### 12.3.1 按盘符或文件夹删除派生数据

如果只想清除某个盘符或文件夹内素材产生的数据，而不影响其他来源，请打开 `Settings → Data & Reset → Delete generated data by source`：

1. 从下拉框选择盘符，或点击 `Choose folder` 选择一个文件夹。
2. 点击 `Analyze generated data`。界面会分析应用索引与派生文件，并只遍历所选来源的文件名和时间戳以精确反查孤立缩略图；不会读取文件内容，也不会删除或改写原始素材。
3. 核对图片索引、模型向量、缩略图、视频清单、帧、转写/OCR、视频语义索引和共享可重建缓存的分类预览。
4. 点击 `Confirm delete generated data` 执行。预览令牌 15 分钟后失效；索引在预览后发生变化时必须重新分析。

该操作不会删除原始图片、原始视频、已安装模型或人工维护的素材库分类/标签。图片与视频帧共用的 DINO/CLIP 分片只会移除命中当前来源的记录，其他来源记录保留；相关共享缓存会失效并在后续使用时重建。正在扫描、抽帧、建向量或执行其他数据维护任务时，清理会被拒绝，应先停止任务再重试。

所选盘符或文件夹必须当前在线、可访问且为普通目录；符号链接不能作为清理范围。Native 索引删除后会自动执行物理压实，失败/诊断记录和输入拒绝缓存也会按来源过滤；没有视频命中时不会删除视频共享缓存。缩略图只有在路径、mtime、策略版本和尺寸桶能够精确复现缓存键时才删除，仍无法可靠归属的历史孤立缓存不会被猜测删除。执行结果出现部分失败时不要立刻重复操作，先保留错误信息并重新分析范围。

主体精细搜索的 `subject-embeddings` 独立缓存也按来源清理，包含主体裁剪、人脸、行人重识别和负例向量。历史审计记录默认保留；显式选择移除来源痕迹时，仅处理白名单中的 `value-automation` 状态与输出文件，其他日志保持原样。因此主要分类为 0 不代表所有历史路径痕迹均被清除。发生晚期失败时，结果会保留已经完成的图片、视频和主体向量清理统计并提示部分完成；请先重新分析，不要直接重复执行。不要在应用运行时手工编辑这些 JSONL 或日志。实现与复检见[按来源派生数据清理专项](../current/2026-08-23-source-derived-data-cleanup.md)和[全面审计修复 TODO](../current/2026-09-30-comprehensive-audit-fixes-todo.md)。

### 12.4 搜索

图片查询：

- `Query` 选择图片。
- `Paste` 使用剪贴板图片。
- 将图片拖入查询区。
- `Refresh` 重跑当前查询。

文本查询：

- 在 `Text query` 输入描述。
- 按 Enter 或点击 `Search Frames` / `Multi`。

高级参数：

- 模型：`CLIP` 或 `DINO`。
- 后端：`GPU` 或 `CPU`。
- `topK`：20 至 1000。
- `Multi`：组合图片与文字条件。
- 视图：`Videos` 或 `Frames`。
- 帧视图排序：`By Score` 或 `By Time`。

### 12.5 结果操作

- 打开视频，并跳转到命中的时间点或时间范围。
- 在资源管理器中显示视频。
- 使用结果帧继续相似搜索。
- 对支持的媒体执行内嵌字幕提取。
- 在统一搜索中勾选结果后导出 JSON、CSV、CMX3600 EDL 或 FCPXML；无有效视频时间范围的项目会被明确跳过。

搜索结果为空时，依次检查：是否完成视频扫描、是否生成帧、所选模型是否已有帧向量、是否已加载数据，以及 `topK` 和查询条件是否合理。

### 12.6 播放器命中导航与片段导出

从搜索结果打开视频时，受控播放器会显示当前命中序号、类型、起止时间、查询、对白或描述以及证据来源。可以使用按钮、`Alt+←` / `Alt+→` 或 `[` / `]` 在同一视频的上一处和下一处命中之间移动。

播放器顶部的“片段导出”区域提供独立入点和出点：

1. 使用数值框、滑块或时间线调整范围；点击“设为当前”把当前播放位置设为入点或出点。
2. 搜索命中带时间范围时，可点击“使用命中范围”。
3. `I` 设置入点，`O` 设置出点；入点/出点精调按钮每次移动一帧。
4. 数值框普通 `↑` / `↓` 按 1 毫秒调整，`Shift+↑` / `Shift+↓` 按所选帧率移动一帧。
5. 选区时间线获得焦点后，`←` / `→` 移动 1 秒，按住 Shift 移动 5 秒，`Home` / `End` 跳到选区边界。
6. “循环选区”会在播放越过出点后返回入点，便于检查剪辑边界。

导出格式：

- `导出 MP4`：通过可用的 FFmpeg 把选区重新编码为 H.264/AAC MP4。导出范围至少为 40 毫秒，不能覆盖源视频；长片段耗时和临时磁盘占用会随时长增加。
- `导出 EDL`：按所选时间线帧率生成 CMX3600 EDL。
- `导出 FCPXML`：按所选时间线帧率生成 FCPXML 时间线并引用原始本地素材。

EDL/FCPXML 的帧率应与目标剪辑工程一致。导出使用系统保存对话框，只接受播放器启动时授权的源视频；源文件失效、选区越界、FFmpeg 不可用或已有导出进行中时会拒绝操作并显示原因。

## 13. Asset Library / NekoSearch 素材库

Asset Library 使用 Image Search 索引作为素材来源，提供分类、标签、AI 建议、聚类、审核反馈、相似检索和备份。

### 13.1 首次使用

1. 先在 Image Search 完成图片扫描和必要向量构建。
2. 打开 `Asset Library`。
3. 点击同步入口，把 Image Search 索引同步到素材库。
4. 等待素材数量和存储状态更新。

顶部状态区会显示素材总数、已分类、未分类、建议、已移除、聚类和任务进度。存储显示 `read-only` 或 `unavailable` 时，不要继续进行批量写入，应先备份并排查。

### 13.2 Assets 素材

素材视图支持：

- 按文件名过滤。
- 按分类、标签、未分类和已移除状态筛选。
- 排序与分页。
- 打开文件或在资源管理器中定位。
- 单选、多选、全选当前页。
- `Shift+点击` 进行连续范围选择。
- 批量分配分类或标签。
- 移除素材、恢复素材和撤销上次移除。

“移除”针对素材库记录，不等同于删除源图片。执行前仍应查看确认提示和当前筛选范围。

### 13.3 Categories & Tags 分类与标签

分类功能：

- 创建、重命名和删除分类。
- 建立父子分类层级。
- 拖放分类调整父级。
- 管理分类参考图。
- 从文件选择、粘贴或已有素材添加参考图。
- 查看分类中的全部素材。
- 从分类启动样本搜索或分类聚类。

标签功能：

- 创建、编辑和删除文本标签。
- 调整 CLIP 阈值。
- 构建标签 AI 建议。

删除分类或标签会进入元数据删除历史。可在历史视图恢复、清理或导出记录。清理历史前应先建立素材库备份。

### 13.4 AI Suggestions 建议审核

建议来源可包括参考图和文本标签。

典型流程：

1. 选择建议状态和来源。
2. 生成或刷新建议。
3. 查看候选素材、分类/标签和置信度。
4. 应用建议，或选择忽略。
5. 对结果不满意时调整参考图、标签阈值或搜索学习数据，再重新生成。

人工审核结果会参与搜索学习。错误的大批量审核可能影响后续建议，因此建议分批处理并定期备份。

### 13.5 Sample Search 分类样本搜索

1. 选择样本分类。
2. 设置结果数量和最低分数。
3. 选择是否包含已审核素材。
4. 点击 `Search category samples`。
5. 对结果选择 `Relevant` 或 `Not relevant`。

相关/不相关反馈用于改进该分类的候选排序。应优先标注清晰的正样本和明显负样本，避免把不确定样本强行标记。

### 13.6 Similar Results 相似结果

- 从素材或分类入口启动相似搜索。
- 可以指定把所选相似结果加入哪个分类。
- 可对选中结果标记 `Relevant` 或 `Not relevant`。
- `Clear results` 清空当前结果，不删除素材。

### 13.7 Clusters 聚类

聚类用于从大量素材中发现视觉或语义组，包括：

- 自动分组。
- 分类范围分组。
- 精确重复和近似重复组。
- 人物或通用视觉组。
- CLIP 与 DINO 组合聚类。
- 语义细分与自动标签。

人工操作可包括：

- 合并组。
- 拆分组。
- 把成员移入或移出组。
- 重命名组。
- 忽略组。
- 把稳定组提升为正式分类。

聚类参数会显著影响分组数量和纯度。初次使用建议：

1. 先选择较小目录范围。
2. 使用默认参数构建。
3. 检查代表图和组内一致性。
4. 再逐步调整最小组大小、纯度、语义纯度和最大拆分数。
5. 扩大到全库前建立备份。

### 13.8 Backups 备份

素材库备份功能支持：

- 创建备份。
- 列出备份。
- 校验备份。
- 导入和导出便携备份。
- 删除备份。
- 恢复备份。

新导出的便携备份要求设置 12 至 256 字符的密码，文件内容以加密形式保存。导入时输入对应密码；密码错误或文件内容受损会拒绝导入。请在可靠位置保存密码，软件不提供密码找回功能。历史明文便携备份仍可导入；便携备份加密不等于源媒体或工作中的向量数据库已加密。

恢复操作会替换当前素材库元数据。恢复前软件会尝试建立保护性备份，但仍建议先把关键备份导出到另一个磁盘。

`Report` 可导出素材库统计、分类、标签和删除历史等 JSON 报告。报告不是完整可恢复备份。

## 14. Duplicate Finder 重复文件查找

面板包含三种模式：

### 14.1 Duplicates 完全重复

1. 选择目录。
2. 点击 `Scan`。
3. 软件按文件大小筛选候选，再进行字节级哈希比较。
4. 结果按组展示副本数量、单文件大小和可回收空间。

该面板当前以分析和定位为主。确认删除前应在资源管理器中核对文件用途和备份情况。

### 14.2 Largest 最大文件

1. 选择目录。
2. 点击 `Analyze`。
3. 显示最多 100 个最大文件。
4. 点击 `Show` 在资源管理器中定位。

启用 AI Control 且 token 包含 `search` scope 后，可直接调用 `storage.largeFiles` 并使用 `scope: "computer"` 自动发现本机可访问磁盘、扫描大文件、汇总全局 Top-N 和清理风险分类；使用可选的 `rootId: "drive-c"` 可只扫描 C 盘，接口不接受绝对路径。不需要先在“数据源”中添加磁盘。需要限制到常用范围时可将 scope 改为 `user`、`downloads` 或 `temporary`。响应只返回磁盘标识、磁盘标签和磁盘内部相对位置，不返回绝对路径；如果 `complete` 为 false，表示存在无权限、不可访问或达到条目上限的范围，只能视为部分结果。针对已登记本地磁盘或文件夹的精确范围查询仍可使用 `folder.largeFiles`。两种只读能力都支持大小阈值、Top-N、文件年龄和清理分级筛选，且不提供删除操作。`low-risk` 只表示旧缓存或临时文件候选；仍需关闭相关程序并人工核对。`review` 不能仅凭大小删除，`protected` 应使用 Windows 存储、卸载、休眠或回收站入口处理。

### 14.3 Similar 相似图片

感知相似图片由已建立索引的 Image Search 引擎处理。点击 `Open Image Search` 进入相似图片工作流。

扫描过程中可点击 `Stop`。权限不足、长路径、离线磁盘或文件被占用时，结果可能不完整。

## 15. Batch Rename 批量重命名恢复

该工具通过图片视觉哈希，把“已被改名的图片”与保留原始名称的图片目录匹配，并把结果复制到输出目录。

### 15.1 目录含义

- `Origin`：保留原始文件名的图片目录。
- `Modified`：图片内容相同或相近，但文件名已经变化的目录。
- `Output`：写入恢复后名称的输出目录。

为降低风险，三个目录应使用不同路径，输出目录不要指向原始目录或改名目录。

### 15.2 参数

`Threshold`：

- 匹配阈值越高，误匹配更少，但未匹配数量可能增加。
- 建议先用默认值试跑并抽查结果。

`Conflict`：

- `Keep best match`：保留得分最高的匹配。
- `Skip conflict`：有冲突时跳过。
- `Keep both`：当本次任务中的多个修改文件匹配同一原图时，为后续候选追加序号。

这些冲突策略用于处理本次任务中的匹配冲突。输出目录已有同名文件时，`Keep best match` 和 `Skip conflict` 会跳过该输出，`Keep both` 会追加序号；写入期间出现的同名目标也受保护。`Keep best match` 先按得分选定候选再复制，避免边复制边替换留下旧结果。复制前后都会检查源文件是否变化，变化时跳过并提示。仍建议使用专门的输出目录，方便完成后抽查和整理。

### 15.3 执行

1. 选择三个目录。
2. 设置阈值和冲突策略。
3. 点击 `Start`。
4. 查看进度、匹配数、未匹配数和 ETA。
5. 需要中止时点击 `Stop`。
6. 完成后抽查输出文件，再决定是否进行后续整理。

应用会拒绝把输出目录设置为原始目录或改名目录，但任务不是事务式批处理：点击 `Stop` 或中途出错时，已经复制成功的文件会保留，不会自动回滚。开始前应备份重要文件，并使用空输出目录；不要把输出结果未经抽查直接覆盖唯一原件。

## 16. App Storage 应用占用分析

App Storage 扫描已安装应用及其关联路径，估算安装目录、用户数据和缓存占用。

### 16.1 扫描和结果

- 点击 `Scan` 开始。
- 点击 `Stop` 中止。
- 使用搜索框按应用名称或发布者筛选。
- 可按 `Size`、`Name` 或 `Publisher` 排序。
- 展开应用可查看安装路径、数据路径、缓存路径、估算值和不可访问项。
- `Open` 打开可访问路径。

结果是基于注册信息和可访问路径的分析值。权限不足、符号链接、共享目录或动态缓存可能导致估算值与 Windows 设置中的数值不同。

### 16.2 保存的扫描

- 扫描结果会保存并在下次启动时自动加载。
- `Clear` 只清除保存的扫描结果，不卸载应用，也不删除应用数据。

面板显示的 `Uninstall` 信息用于识别卸载入口；执行任何卸载前应确认应用、数据备份和 Windows 提示。

## 17. Remote Terminal 远程终端

Remote Terminal 提供 SSH 终端、连接测试、服务器指标、SFTP 浏览和文件传输。

### 17.1 新建配置

点击 `+ New`，填写：

- `Name`
- `Host`
- `Port`，默认 22
- `Username`
- `Auth`
  - `Password`
  - `Private Key`
- 私钥模式下填写本机私钥路径。

保存后可使用：

- `Connect`：打开 SSH 终端。
- `Test`：测试连接并显示阶段和延迟。
- `Mon`：采集 CPU、内存和磁盘指标。
- 文件按钮：打开 SFTP 浏览。
- `Edit`：编辑。
- `Dup`：复制配置。
- `Del`：删除配置。
- `Test All` / `Collect All`：批量测试或采集。

### 17.2 首次主机指纹确认

首次 SSH/SFTP 连接时，软件会显示服务器主机指纹。

正确做法：

1. 通过服务器管理员、云控制台或其他可信渠道独立核对指纹。
2. 指纹一致后再选择信任并保存。
3. 已保存指纹突然变化时，不要直接清除并接受新指纹；先排除服务器重装、密钥轮换或中间人攻击。

### 17.3 密码和私钥口令

凭据选项：

- `Session`：只保存在当前应用进程内存中，退出应用后清除。
- `Protected`：使用 Windows 当前用户的 DPAPI/safeStorage 加密后保存；渲染界面不会读取已保存明文。
- `Forget` 或配置旁的锁按钮：删除已保存凭据。

如果 Windows 凭据加密不可用，Protected 保存会失败。不要把私钥口令写入配置名称、主机名或其他明文字段。

### 17.4 SSH 终端

- 连接后会建立终端标签页。
- 可同时维护多个会话。
- 关闭会话前确认远程命令已经完成。
- 网络中断后根据状态重新连接，不要假定未返回的远程命令已经回滚。

### 17.5 SFTP 文件浏览

SFTP 浏览器支持：

- 编辑远程路径并按 Enter。
- 返回上级目录。
- 快速访问 `/`、`/home`、`/var/log`、`/etc`、`/tmp`、`/var/www`、`/opt`、`/root`、`/usr`。
- `Upload` 选择本地文件上传到当前远程目录。
- 对远程文件执行下载，选择本地目标目录。
- 查看传输任务状态。

远程权限、磁盘空间、连接中断和符号链接都可能导致传输失败。重要文件传输完成后，应在目标端校验文件大小或哈希。

## 18. 数据位置、备份与恢复

### 18.1 默认数据目录

主要用户数据位于：

```text
%APPDATA%\floating-clock-electron
```

可通过 `Settings > Data > Open Config Folder` 打开。

主要内容包括：

| 文件或目录                         | 用途                                     |
| ---------------------------------- | ---------------------------------------- |
| `floating_clock_settings.json`     | 主题、布局、面板状态、尺寸、语言等设置   |
| `clock_config.json`                | Folders 快捷方式和 Prompts 提示词        |
| `image-search-index\`              | 图片索引                                 |
| `thumbcache\`                      | 图片缩略图缓存                           |
| `image-search-queries\`            | 图片搜索的临时/持久查询图                |
| `media-search\`                    | 视频清单、帧、缩略图、向量和临时数据     |
| `media-search-queries\`            | 媒体搜索查询图                           |
| `asset-library\`                   | 素材、分类、标签、聚类、建议等元数据     |
| `asset-library-backups\`           | 素材库本地备份                           |
| `vector-db\`                       | 向量数据库、嵌入缓存和相关派生索引       |
| `app-storage-cache.json`           | 应用占用扫描缓存                         |
| `remote-terminal-profiles.json`    | 远程终端连接配置，不包含密码或私钥口令   |
| `remote-terminal-credentials.json` | Windows 加密后的远程凭据，不含保存的明文 |

实际内容会随已使用的功能变化，不存在的目录不代表安装损坏。

### 18.2 推荐备份

退出 Siftory 后再备份，避免复制到正在写入的数据库或索引。

最低备份：

1. `floating_clock_settings.json`
2. `clock_config.json`
3. Remote Terminal 配置和凭据文件

完整备份：

1. 正常退出应用。
2. 把整个 `%APPDATA%\floating-clock-electron` 复制到另一个磁盘。
3. 对 Asset Library 另外创建并导出便携备份。
4. 记录软件版本和备份日期。

图片和视频源文件不在应用数据目录中，必须按自己的素材备份策略另行保护。

### 18.3 恢复原则

- 配置文件恢复：应用退出后替换对应 JSON，再启动检查。
- 素材库恢复：优先使用面板内置 Backup/Restore，不要直接覆盖正在打开的 SQLite 文件。
- 索引损坏：保留源图片或视频，必要时清理派生数据后重新建库。
- 跨机器恢复远程凭据时，Windows DPAPI 加密内容通常只对原 Windows 用户上下文有效；应准备重新输入凭据。

## 19. 性能、磁盘空间与模型

### 19.1 哪些操作开销较大

- 整盘图片扫描。
- 原生缩略图重建。
- CLIP/DINO 全库向量构建。
- 大型视频库抽帧。
- 视频帧 CLIP/DINO 向量构建。
- 全库素材聚类和语义细分。
- 大目录重复文件哈希扫描。

### 19.2 降低资源占用

- 先选具体素材目录，不要一开始扫描整个磁盘。
- 大任务分目录执行。
- CPU 压力过高时降低 `Jobs`。
- GPU 后端异常时改用 CPU。
- 不需要扩展评分时关闭 `Scores`。
- 搜索时先使用较小 `topK`。
- 定期清理不再需要的查询图、临时缓存和可重新生成的旧数据。
- 清理前先分清“临时缓存”“索引/向量”“素材库元数据”和“源文件”。
- 长时间扫描后关注日志、失败记录、向量分片、缩略图缓存和诊断备份的增长，避免用户数据目录持续占满系统盘。
- 应用正在扫描、建向量或写入素材库时，不要手工删除其数据目录；先停止任务并正常退出。

### 19.3 模型

当前 Online 安装包不内置模型权重。DINO、CLIP 和多语言编码器在用户启动相应准备流程时从固定上游另行下载；主体相关本地模型需要用户准备文件并完成导入确认。深层视频语义、对白、人脸、行人和分割等可选能力还可能需要另行准备模型及运行时。各模型按其来源条款使用，第三方权重不属于 Siftory 的原创源码。不能以某一基础搜索可用推断所有能力均已就绪。搜索面板显示模型缺失、校验失败或初始化失败时：

1. 确认安装完整。
2. 确认模型目录未被安全软件隔离。
3. 确认磁盘空间足够。
4. 尝试 CPU 后端。
5. 保留错误信息和模型名称用于排查。

导航栏中的模型检测区统一显示图片、视频、音频和主体模型。点击“检测”会执行较慢但更可靠的运行时深度检查；只有状态为 `ready` 的模型才算可以执行对应任务。

开发或本机评估环境已经准备好仓库内候选文件时，可在项目目录执行：

```powershell
npm.cmd run models:local:install -- --accept-local-user-models
npm.cmd run models:local:verify
npm.cmd run models:video:install -- --accept-external-model
npm.cmd run models:video:verify
```

安装命令会要求本地使用责任确认，校验清单大小与 SHA-256，并通过隔离 ONNX 检查和原子事务写入 `%APPDATA%\floating-clock-electron\models`。视频命令只安装并验证开发态应用使用的固定 Ollama 模型，不会安装或更新 Ollama 本体。两者都不会把候选加入发布包，也不会默认覆盖不同的用户模型或模型 digest。应用已经打开时，完成后再次点击导航栏“检测”或重启应用。

## 20. 常见问题与故障排查

### 20.1 面板看不到

1. 按 `Ctrl+Shift+Alt+R` 尝试恢复全局可见状态；旧版用户也可暂用兼容键 `Ctrl+Shift+Alt+Q`。
2. 按 `Ctrl+Shift+Alt+P` 把面板吸附回工作区。
3. 打开 `Settings > Layout` 检查对应面板是否启用。
4. 按 `Ctrl+Shift+Alt+S` 显示全部面板。
5. 检查是否被其他面板遮挡，使用标题栏“置后”或点击目标面板。

### 20.2 Settings 不能取消

这是设计行为。Settings 是面板管理和恢复入口，始终保持启用。全局隐藏快捷键仍可临时隐藏整个工作区。

### 20.3 取消置顶后仍在顶部

- 确认图钉状态已经切换为“不置顶”。
- 某些全屏、系统工具或窗口焦点切换会影响视觉层级，可先点击其他普通窗口验证。
- 若状态与行为不一致，退出后重新启动，并记录发生步骤。

### 20.4 全局快捷键无效

1. 打开 `Settings > System`。
2. 点击 `Register Hotkeys`。
3. 查看是否有快捷键注册失败提示。
4. 关闭占用相同组合键的软件后重试。

### 20.5 Image Search 没有结果

依次检查：

1. 是否添加了正确扫描路径。
2. 是否完成扫描。
3. 语义/向量搜索是否完成相应 CLIP 或 DINO 构建。
4. 查询图是否有效。
5. 阈值是否过高。
6. 文件名过滤是否过严。
7. `topK` 是否过小。
8. 中文查询是否使用 Auto 或 Multilingual 文本编码器。

### 20.6 Media Search 不能搜索

依次确认：

1. 视频是否已扫描。
2. FFmpeg 是否可用。
3. 是否已抽帧。
4. 当前模型的帧向量是否已构建。
5. 高级模式下是否需要点击 `Load Data`。
6. 查询模式、模型和后端是否匹配已有数据。

### 20.7 缩略图空白或错误

- 点击刷新。
- 确认源文件仍存在且可读。
- 对图片索引使用记录重算或缩略图重建。
- GPU 路径失败时改用 Auto 或 CPU。
- 不要删除源图片后只依赖缩略图缓存。

### 20.8 素材库显示只读或不可用

1. 停止当前任务。
2. 不继续批量编辑。
3. 创建或复制现有备份。
4. 退出应用后检查磁盘空间和目录权限。
5. 使用内置校验/恢复功能。
6. 不要在应用运行时手工替换 `asset-library.sqlite`。

### 20.9 文件操作失败

- 检查权限、只读属性、目标磁盘空间和文件占用。
- 网络路径断开时重新连接。
- 路径过长或包含特殊设备路径时改用较短目标目录。
- 批量操作出现部分失败时，先刷新目录并核对实际文件状态，再决定是否重试。

### 20.10 Remote Terminal 无法连接

1. 检查主机、端口和用户名。
2. 检查密码、私钥路径或私钥口令。
3. 使用 `Test` 查看失败阶段。
4. 检查服务器 SSH 服务、防火墙和网络。
5. 主机指纹变化时先独立核验，不要直接清除信任记录。
6. Protected 凭据无法解密时点击 Forget 并重新输入。

### 20.11 磁盘空间不足

优先排查：

- `media-search\frames`
- `media-search\vectors`
- `thumbcache`
- `vector-db\embeddings` 等向量分片
- `image-search-scan.log` 和 `embedding_failures.jsonl`
- `asset-library-backups`、恢复快照和诊断备份
- 不再需要的安装包和旧构建产物

当前版本的日志和派生向量可能随长期扫描持续增长。优先使用面板内已有的清理入口；如果面板没有对应入口，先退出应用、记录各目录大小并备份素材库元数据，再按维护说明处理。不要在应用运行时直接删除 SQLite、JSONL、索引或向量文件，也不要把源素材当作缓存清理。删除任何数据前先确认它是否是唯一备份。

只清理某个盘符或文件夹产生的数据时，优先使用 `Settings → Data & Reset → Delete generated data by source`，先分析再确认；不要按盘符名称猜测并手工删除共享向量分片。

## 21. 安全操作清单

执行以下操作前建立备份：

- `Reset Config`
- `Clear Video Data`
- `Delete generated data by source`
- 素材库恢复或删除备份
- 清理素材库删除历史
- 大批量分类、标签或建议应用
- File Manager 批量移动、重命名或删除
- Batch Rename 输出结果覆盖或替代现有工作流
- 清理索引、向量或缩略图目录

始终遵守：

1. 重要源图片、视频和远程文件保留独立备份。
2. 整盘扫描前先用小目录验证。
3. 批量操作先抽样，再扩大范围。
4. 不在应用运行时手工编辑 SQLite、JSONL、索引和向量文件。
5. 不接受未经独立核验的 SSH 主机指纹变化。
6. 不把安装包、索引缓存和源素材混放为唯一副本。
7. 任务显示运行中时先 Stop，再退出或关机。

| Suggestion | AI 根据参考图、标签或反馈生成的分类/标签候选                   |
| Cluster    | 按视觉、语义、人物或重复关系自动形成的素材组                   |
| DPAPI      | Windows 当前用户上下文提供的数据加密能力                       |
| SFTP       | 基于 SSH 的远程文件浏览和传输协议                              |

## 23. 同步已删除的源文件

当已经加入索引的图片或视频在资源管理器中被删除后：

1. 打开 `设置 → 数据与重置 → 来源索引维护`。
2. 选择原来的盘符或文件夹。
3. 点击“检查已删除的源文件”。此步骤只读取文件状态，不修改索引。
4. 查看图片、视频、缺失和无法访问记录的数量。
5. 点击“确认同步索引”。系统会再次检查文件，避免把预览后恢复的文件误删出索引。

同步完成后，失效图片会从 Native 搜索索引移除，对应图片向量和可归属缩略图会清理，并自动启动素材库同步；失效视频会标记为缺失，不再参与搜索或建库。原始图片和视频不会被删除。

如果盘符未挂载、移动硬盘断开、网络目录离线或目录无法读取，系统会阻止同步。不要为了通过检查而新建同名空目录；应先恢复真实来源连接。需要回收整个盘符或文件夹产生的视频帧、转写和语义数据时，使用同一区域的“按来源删除派生数据”，先分析再确认。

## 24. 统一搜索与准备中心

### 24.1 添加来源并准备素材

1. 从导航栏打开来源管理，添加需要检索的本地文件夹。首次使用建议选择少量图片和视频组成的测试目录。
2. 检查来源健康状态和模型检测结果，确认路径在线且可读。挂载网络目录和 SFTP 来源还需要有效连接、权限及对应配置。
3. 打开准备中心，查看总体状态、来源目录、扫描、特征、索引等阶段。根据界面列出的下一步操作准备素材库。
4. 在任务中心观察阶段、完成数量、失败数量和错误原因。仅对当前任务提供的暂停、恢复或停止动作进行操作。
5. 准备结束后提交查询。某些模型未就绪时，界面会说明当前可用搜索能力；元数据搜索和完整语义搜索的结果范围可能不同。

### 24.2 提交查询与筛选

统一搜索支持输入文字、使用参考图片，并按来源、媒体类型等条件缩小范围。高级筛选可限定文件属性、媒体时长、评分和收藏等已提供的条件。输入与筛选组成一次查询；切换来源或模型状态后，应重新查询以取得对应结果。

文字相关度、视觉相似度、对白和元数据命中使用不同的证据来源。检查结果中的命中依据、素材来源和可用状态；相关度分数不是事实保证。模型缺失或来源离线时，先处理界面提示再扩大查询范围。

### 24.3 命中导航与后续操作

图片结果可打开、定位原文件或加入素材集合。视频结果可打开内置播放器，并在命中时间范围间切换。对白或视频语义命中需对应索引已经建立；来源变动时可能需要重新检查或准备。

结果支持按界面提供的格式导出清单或剪辑引用。JSON/CSV 用于结果信息交换；EDL/FCPXML 用于剪辑引用，不能代替被引用的原素材。播放器片段导出还需要可用的媒体工具、写入权限及足够空间。是否兼容某一剪辑软件版本，应通过实际导入确认。

### 24.4 健康检查与恢复

准备中心和模型检测区会显示模型、存储、来源及任务健康信息。按提示先检查路径、模型状态与磁盘空间。修复入口区分检查和会改写派生数据的操作；需要确认的重建或清理应先核对影响范围。

任务中断后，持久任务与仅本次运行的任务恢复能力不同，以界面状态为准。不要手工删除正在使用的索引、事务文件或模型目录来强行解除忙碌状态。恢复来源连接后重新检查；如果仍失败，保留脱敏诊断和错误信息用于排查。
