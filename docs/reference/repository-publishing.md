# GitHub / Gitee 源码公开准备

> 状态：当前  
> 更新日期：2026-10-10

当前版本为 `1.0.1-alpha.2`，属于 Alpha 测试版本。项目原创代码采用 [Apache-2.0](../../LICENSE)，包括商业用途在内均按许可证免费使用，无须购买项目商业授权，见 [开源许可说明](../../SOURCE_AVAILABILITY.md)。第三方组件保留各自许可，模型和用户数据不进入源码提交。

## 上传范围

上传项目源码、配置、测试、资源清单和必要的第三方许可声明。不要上传模型权重、用户图库、索引数据库、运行日志、安装包、开发依赖、身份证明或签署材料。第三方组件继续适用各自许可。

当前工作区存在大量已有改动。不要直接执行 `git add .` 或把整个项目文件夹上传。`.gitignore` 无法清除已经跟踪的文件或历史提交中的个人信息。

## 发布顺序

1. 检查当前文件与历史提交中的个人路径、凭据和登记材料；检查大文件与第三方许可。
2. 为公开仓库整理独立源码副本。若旧历史含私人信息，使用经过审查的副本建立新仓库，不推送旧 `.git`。
3. 定稿许可文本，写清个人免费范围、商业使用授权方式、修改和再分发条件，并同步 README 与软件条款。
4. 执行类型检查、代码检查、相关测试和受检构建，保留结果。
5. 作者创建 GitHub / Gitee 仓库，确认仓库地址与提交者身份。逐项审查暂存文件后提交、设置远程地址并推送。
6. 安装包另行通过打包与安装验证；GitHub Release 标记为预发布。源码仓库上传不代表安装包已经完成验收。

本次没有创建远程仓库、推送提交或创建发布标签。当前检查结果见 [准备记录](../current/2026-10-10-alpha-repository-preparation.md)。已提交软著申请的 V1.0.0 材料继续保留原件，不随 Alpha 改写。
